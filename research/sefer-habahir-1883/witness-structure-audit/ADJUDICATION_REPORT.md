## 6. IDENTITY TIER SEPARATION (Source Work ≠ Book ≠ Edition ≠ Textual Version ≠ Witness ≠ Digital Object ≠ Locator)

Applying the 7-tier separation named in `research_intake_foundation_contract_law` §9.2:

1. **Source Work** — "Sefer HaBahir," the medieval Kabbalistic text attributed to R. Nechunya ben HaKanah (a literary/textual entity, not tied to any one printing).
2. **Book** — "Sefer HaBahir with the Or HaGanuz commentary" as a bibliographic *work-plus-commentary* unit (distinct from a bare-text printing of the Bahir alone, e.g. Amsterdam 1651).
3. **Edition** — the **1883 Vilna printing**, edited by Shmuel Luria, published by the Romm press (distinct from the 1913 Vilna reprint, the 1951 Margaliot edition, the 1994 Abrams edition, etc.).
4. **Textual Version** — the specific collated/arranged textual arrangement Luria produced for this edition (his stated methodology: alphabetized discourse-units, collated variant readings, incorporated Vilna Gaon glosses — see PDF p44). This is a *recension*, distinct even from another copy of the same 1883 print run if hand-corrected differently.
5. **Witness** — **this specific physical exemplar**: the National Library of Israel's copy, call number `S 23 A 11927`, barcode `1805775-30` (as opposed to some other library's copy of the same 1883 print run, which is a different Witness of the same Edition).
6. **Digital Object** — the Google Books PDF digitization of that Witness: `gallery/Book/Sefer_HaBahir_1883.pdf`, sha256 `b099f2298525c71e7abd45e6132610525fef7ccb8a8f3be338cf4e2404a57067` (a re-scan of the same physical Witness, or a different digitization vendor's scan of it, would be a *different* Digital Object of the *same* Witness).
7. **Page/Span/Region (Locator)** — e.g. "PDF page 32," "leaf יא recto," "printed page 22" — a locator into the Digital Object, not an identity in itself. This scan's `source_ref` convention (`book:sefer-habahir-1883#p<PDF_PAGE>:<BLOCK_ID>`) operates entirely at this tier.

**Key separation point:** none of tiers 1–6 are interchangeable. "1883" names the *Edition* (tier 3); the sha256 names the *Digital Object* (tier 6); "S 23 A 11927" names the *Witness* (tier 5); "PDF page 32" is a *Locator* (tier 7) that presupposes, but does not itself establish, which Digital Object it is a locator into.
