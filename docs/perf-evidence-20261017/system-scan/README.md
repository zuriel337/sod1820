## 7. בדיקות (קו בסיס, בידוד מלא)

הרצה של כל `test/*.test.mjs` תחת `scripts/ci-isolation/run.mjs` (רשת חסומה, concurrency 3). **ההרצה לא הושלמה: נעצרה לבקשת צוריאל, ולכן זה אינו קו בסיס ואין לצטט ממנה אחוזי הצלחה.** נכון לעצירה: 949 עברו ו־77 נכשלו (ספירת בדיקות בודדות, חלק מהקבצים טרם רצו).

מה שאפשר לומר ממנה: (1) רוב הכשלים הם בדיקות הדפדפן של ELS (`els-native-ui-browser`) עם `net::ERR_NETWORK_ACCESS_DENIED` לשרת loopback — אותו פער שתוקן היום בטסט שלי: השרתים אינם רשומים ב־`permitLocalServer`, ולכן הבדיקות האלה אינן יכולות לרוץ בבידוד המלא; (2) כשלים ידועים מראש שנכשלים זהה גם בבסיס: `date-display-rule-2029`, `companion-2029-public-source-shortcuts` #8; (3) לא סווגו שאר הכשלים.

תופעת לוואי שנמצאה: הרצת הסוויטה שינתה את הקובץ המנוהל `public/tzofen.html` (כותרת gzip שונה בנתוני `torah-data`) ויצרה `scripts/spatial/__pycache__`. שניהם שוחזרו ונמחקו; כלומר יש בדיקה שכותבת לקובץ מנוהל תחת `public/` — ממצא נפרד לבעלים.
