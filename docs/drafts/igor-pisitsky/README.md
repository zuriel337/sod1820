## צפייה והמשך הכנה

`preview.html` מדגים שלוש מטריצות עם סיפור ליד כל אחת במחשב, ובסידור אנכי בטלפון. `matrices/` כולל SVG עם מיקומי האותיות ו־PNG מוכנים לצפייה. `originals/` מכיל את חמש התמונות שנמסרו.

`post-content.html` מכיל את חומרי המחבר. `ai-addition.html` מכיל הערות בדיקה נפרדות, מיועד לשדה הקיים `posts.ai_addition`. `post-draft.json` הוא מניפסט הכנה בלבד, ולא מטען API. בעת פתיחת הדף יש לבחור את רשומת המחבר הקיימת, להעלות את התמונות למקום המאושר ולחבר את הקישורים; השמות כאן מקומיים. מזהי פרופיל/פוסט/מחבר וכתובת פרסום לא הומצאו. תרגום ממתין למסלול הקיים; האנגלית המקורית נשמרה.

אפשר להציג מספר ממצאים וסיפור ליד כל אחד באותו דף; כך בנויה הטיוטה. לא נוסף מנגנון פרסום או דף ציבורי חדש.

## תוצרי הסריקה הקודמת

`derived/` משמר את הצעות ההמשכים בני שתי המילים, צילום שלהן ו־CSV של התאמות הסריקה הקודמת. אלה תוצאות בדיקה מקומית של המערכת על חומר איגור, ולא גילויים שמיוחסים לו. 1,360 הרצפים המספריים הם מועמדים בגבולות הסריקה, ולא 1,360 מסרים עצמאיים. הסריקה הוגבלה לחלון של 950 תאים ולכיווני יחידה; לא נטען שנבדקו כל הדילוגים או כל חלוקות המילים.

## אימות והפקה חוזרת

```sh
node docs/drafts/igor-pisitsky/prepare.mjs
python -m http.server 8090 --directory docs/drafts/igor-pisitsky
```

לצפייה: `http://localhost:8090/preview.html`. ההפקה חוזרת משתמשת ב־`findAtSkips` מתוך `tools/els/els-code.template.html`, ללא מנוע חיפוש חלופי. כל ששת ביטויי הדילוג וההקשר הרציף מבראשית י״א, ח׳ הותאמו לאותיות הקורפוס. `findings.json` כולל את המיקומים, כיוון הדילוג, גבולות החלון ו־SHA-256 של הקורפוס. האימות מקומי בלבד, ואינו אישור שרת הפריוויו.

`browser-check.json` מתעד בדיקת Chromium ב־1440, 390 ו־320 פיקסלים: שלוש המטריצות נטענו, אין גלישה אופקית, שבעת הציטוטים נשמרו, ואין שגיאות דף. נבדק גם צילום הממצא של רמון חזותית. לא שונה קוד מוצר ולכן לא נדרשה בנייה חוזרת של האפליקציה.
