# אהבת תורה — Lossless Reconciliation Crosswalk

> Companion to `docs/research-library/RESEARCH_LIBRARY_FOUNDATION_v1.md` §9. Implements the task's required crosswalk shape: `ORIGINAL ARTIFACT → ORIGINAL ROW/SECTION/ANCHOR → TARGET DOSSIER OBJECT → PRESERVED? → TRANSFORMED? → MERGED WITH? → PROVENANCE → TRUTH STATE → CONFIDENCE → NOTES`.

## Methodology note (read first)

**No original artifact file is edited, moved, or deleted by this reconciliation.** Every one of the 7 prior artifacts (Ledger, Checkpoints 2–5, Coverage-Map, Letter-Reconstruction, Full-Book-Inventory) remains byte-identical on its own branch. "Preservation" in this crosswalk therefore means: **every original row remains reachable, unedited, at its original location**, and this crosswalk records how it relates to everything else — not a re-transcription of every atomic row into a new document (which would itself violate the spirit of "don't create a second store" by duplicating hundreds of rows into a competing copy).

Granularity used below: **one crosswalk entry per finding-cluster/section** (e.g. `LEDGER §3.1`, `CHECKPOINT_4 §A`, `Letter-table dataset rows 1–187`), which is the same granularity every prior task in this dossier has already used to cite and cross-reference material. Where a crosswalk entry covers a range of atomic rows (e.g. "187 rows"), the **count is stated explicitly** so completeness can be checked (`0 unexplained dropped research items` means every atomic row is accounted for inside a named, counted cluster — none sits outside any cluster).

Truth-state column preserves each artifact's **own native vocabulary**, per the task's explicit instruction not to invent one unified lifecycle enum:
- GPT's ledger vocabulary: `SOURCE VERIFIED` / `NEEDS CORPUS VERIFICATION` / `NEEDS ENGINE VERIFICATION` / `INTERPRETATION` / `SCAN/OCR UNCERTAIN` / `AUTHOR_COUNT` / `CITED_COUNT`.
- Claude's coverage-map/inventory vocabulary: `SCANNED_RESEARCH` / `PARTIAL_RESEARCH` / `SEARCH_HIT_ONLY` / `NOT_RESEARCHED`.
- Claude's letter-reconstruction/full-book-inventory vocabulary: `VISUALLY_VERIFIED` / `SOURCE_LOCATED` / `UNCERTAIN` / `UNKNOWN`.
