## Source facts

- **Title:** ספר יצירה המיוחס לאברהם אבינו ע"ה, נסודר בשלימות על פי נוסח הקדוש הארי אשכנזי זל, עם פירוש הגר"א, ונלוה עליו פרי יצחק (Sefer Yetzirah, attributed to Avraham Avinu, with the commentary of the Vilna Gaon and the appended commentary "Peri Yitzchak")
- **Gra-commentary editor:** שמואל בלאאמ"ס אליעזר אהרן לוריא ז"ל ממאהליב (Shmuel, son of Eliezer Aharon Luria, of Mohilev) — per the title page (p.153) and "הצעת המסדר" (p.154)
- **Second commentary author (Peri Yitzchak):** ר' יצחק אייזיק, אב"ד מאהליב, author of "באר יצחק" on Tikkunei Zohar — his Sefer Yetzirah commentary is titled on the title page "ספר יקר המציאות" but runs under the printed header "פרי יצחק"
- **Printer / imprint:** Warsaw ("ווארשא"); printer "האחים לעוונעפשטיין" / Drukarnia L. Lewin-Epstein, Warszawa (per the task dispatch's file description)
- **Extent:** 220 PDF pages (confirmed via the Read tool's page-count report during this batch)
- **Durable source artifact:** `gallery/Book/Sefer Yetsirah.pdf`, canonical Supabase project `linswmnnkjxvweumprav`. Local scratch copy used for this batch: sha256 `2cc0710667dde3db94745b4f652d4b2e3eb8ea9c64424ab52f1f2ce44281c13a`, 51,714,643 bytes.
- **Physical structure (as mapped so far, pp.153-207 only — pp.1-152 and 208-220 UNMAPPED by this dossier):**
  - pp.153-154: title page + "הצעת המסדר" (the Arranger's Presentation, an introduction — NOT titled "דעת הספר")
  - pp.155-195: פירוש הגר"א — the Gra's commentary on Sefer Yetzirah's 6 chapters, cycling through all Mishnayot, with a parallel "פרי יצחק" commentary column on every page; closes with an explicit colophon on p.195 ("סליק פירוש הגר"א")
  - pp.196-202: Hadran (siyum formula) + "ליקוטי הגר"א ז"ל לספר יצירה" (Likutei HaGra — gleanings), closing with "תם ונשלם" on p.202
  - p.203: "סדר הרל"א שערים לפי דעת הגר"א ז"ל" — the Gra's 231-Gates combinatorial table
  - p.204: a geometric letter-diagram (12 Simple Letters on a sefirotic lattice) + start of a second, independent 231-Gates table attributed to Peri Yitzchak
  - pp.205-206: Peri Yitzchak's 231-Gates tables, organized by sefirah/partzuf (Keter/Chochmah/Binah/Da'at observed)
  - p.207 onward (p.207 is this dossier's current edge): "ל"ב נתיבות מבעל פרי יצחק" (The 32 Paths, by Peri Yitzchak) begins
  - **p.208 onward (UNMAPPED):** per the task dispatch that authorized this batch, an "Ari commentary" is expected to begin around here — NOT independently verified by this dossier, as pp.208-220 have not yet been read by any artifact indexed here.
