# מפת הקשר + מד עומק — Preview (PR #1131, טיוטה)

הקבצים: `desktop-*` / `mobile-*` = המפה הקטנה; `depth-*` = כרטיס פוסט 5112 עם מד עומק קטן והתצוגה המורחבת.
תצוגות: `compare` (בלי מד / פסי כיסוי / תוויות), `expanded`, `number1718`, `number1202`, `admin` (מנהל). הערכות: light / parchment / dark.

## מקור הנתונים (קריאה בלבד, 19.10.2026)
- 28 קשרי גרף של צומת פוסט 5112, כולם `documents` מתגיות (787, 1073, 1202, 1718, 363 ועוד).
- `convergence_meter(787|1073|1718|1202|363)` הקיים: שכבות, כרטיסי התכנסות, דרגות זהב/כסף. הנוסחה לא שונתה; הערך הגולמי נשמר כעובדה אינרטית בתוך "פרטי המנוע הקיים".
- חישובים מאומתים: כב בתשרי תשפד = 1718 רגיל / 1202 מסתתר; חרבות ברזל = 1202 מסתתר; המשיח = 363 רגיל.
- 787 ו־1073 הם תגיות בלבד ללא חישוב מאומת הקשור לפוסט.

## מה אינו מומש / חסום
- אין מקור "נגזר מוכן" לרשימת פוסטים: DC_SMART_METER = PROPOSED, קורא מאוחד NOT_MAPPED. הכרטיס הקטן מציג רק כשמועבר `depth` מוכן, אחרת אינו מציג דבר. בניית נגזרת מוכנה (compile-on-change, §29.5) דורשת החלטה ושינוי מסד.
- עצמאות מקורות ומעמד אישור מוצגים "טרם מופה": אין קורא לקבוצות עצמאות ואין שדה אישור בקשרי הגרף.
- אין ציון ואין סיכום: DEC-METER-002 פתוח.
- הכרטיס בצילומים הוא סכמטי (לא רכיב כרטיס הפוסט של הייצור).
