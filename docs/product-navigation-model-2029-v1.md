## Core principle
Global navigation is built from stable semantic homes, not from a flat list of every current tool. New tools/products may be added without redesigning the global shell.

### Stable global destinations
1. Home / Discover — gateway and curated entry surface.
2. World — the shared knowledge reality. Tree/graph/list/time/source/visual are renderers/lenses inside World, not peer product universes.
3. Heichal — deep research/product environment. First-class research products include Number Page, Gematria, ELS/letter-skips and the personal Person/Life Journey product. Additional tools/functions are added inside governed Heichal/product families rather than automatically becoming global-nav items.
4. Updates / Posts — primary editorial publication/update surface. Posts remain important first-class public content, not buried as a minor utility.
5. Archive — visual/media history surface with three primary projections: Reality Stream, Treasures, Galleries.
6. My Workspace — one personal projection, globally invokable through identity/account/navigation/commands/Raziel; multiple entry points do not create multiple personal systems.

### Global capabilities, not destinations
Search / Command, Raziel, Personal Attention/Notifications, Account/My Workspace entry and Language are shell-level capabilities. They remain reachable across the product and do not require separate navigation universes.

## Extensibility law
A new product/tool must first resolve its semantic home. Default: place it inside an existing product family/home, make it discoverable by Search/Raziel/Home where appropriate, and expose access state through existing entitlement owners. Do not add a global top-level navigation item merely because a new function exists.

## Premium placement
Premium/Deep Premium is an access/depth axis, not a separate site section. A premium product such as Person/Life Journey may be promoted on Home, remain first-class inside Heichal, reopen from My Workspace, and be invoked by Raziel while retaining one product identity. Premium indication uses existing Crown Gate/access semantics.

## Language
Hebrew and English are representations of the same navigation model. No second English site tree/navigation. HE uses Hebrew labels/RTL; EN uses KINGDOM RISE labels/LTR while preserving product identity, Research Context, follows, saved state and exact return.

## Tree placement
The Tree is a future World visualization/lens, potentially including a number-focused view. It is not a separate `עץ המספרים` architecture and should not receive global peer status merely because the visualization is visually prominent.

## Posts / Global Now / Reality integration
Publication and Reality Signal remain distinct typed objects/capabilities but may refer to the same event/representation.

- Post with a Reality image/event: Post can be the primary editorial update; Reality Stream projects the same image/signal and links to the Post when relevant. Home/Global Now should not emit duplicate primary cards for the same underlying event.
- Reality-only image/signal: no synthetic Post is required. Global Now may surface `חדש בזרם המציאות` and open the Reality item/viewer directly.
- Reality item later gains a Post: link the new Post to the existing signal/representation; do not duplicate the image/identity. Reality can expose `קרא את הפוסט/המחקר המלא`.
- Post with multiple images: only selected images/signals enter Reality. Being embedded in a Post does not automatically make every image a Reality item.

Global Now / Latest Updates should eventually be a typed update projection rather than a posts-only list. Candidate update types include Post, Reality Signal, Convergence/Topic, Book/Source, ELS/Cipher, Research publication, Journey/Product release and other governed publication/event families. The projection must deduplicate representations of the same underlying event/identity and retain source/type provenance.

## Deliberate boundary
This document does NOT define the ranking/importance hierarchy of Global Now. Update prominence, editorial priority, category weights, convergence prominence, recency, curation and deduplication policy require a separate owner-resolved ranking/editorial projection decision before Home final composition. Do not smuggle those semantics into navigation code.
