## 12.10.2026 — automatic expression-plan continuation (branch-only)

The user's intended unit is **a user-submitted series of expressions**, not a manually selected reversal. `elsAutomaticResearchPlan.js` now derives the original, whole-expression reversal, per-word reversal and final-word reversal for each submitted expression. It canonicalizes Hebrew spelling for deduplication while retaining every source/rule derivation on the row. The existing iframe `FORMS` registry remains the only authority for its eight Split/Join forms: a bounded read-only `preview-forms-batch` command returns those rows without launching the iframe's own search. The host merges them into the same plan, and the existing adaptive scanner calls the canonical `els-search-bridge` page endpoint. It does not compute occurrences or create a second engine.

The Research form can run that plan in slices of eight variants with explicit continuation and per-variant keyset page continuation. A stopped slice does not skip an unscanned candidate. Results distinguish unscanned, failed, partial and returned pages, retain the derivation, and still require exact replay before loading the shared matrix. The single-term manual form remains available; it is not a prerequisite for automatic series research. No Classic structure, schema, product rows or production deployment changed in this continuation. A plan is local transient research state, not a new Finding store, Journey or Truth claim.
