## 1. `docs/sod1820-system-frame-contract-v1.md` — 2027 Adaptive Shell delta

### Supersede as presentation-specific

The following historical shape no longer controls future UI:

- mandatory three persistent visual layers as fixed placements: Top Navigator + Context Rail + Bottom Control Layer;
- fixed Top Navigator category order / permanent mega-menu model;
- fixed One Dock / five-slot vocabulary as the universal form;
- requirement that fast navigation specifically lives in a top bar;
- Heichal as a separate mandatory immersive/spatial destination that owns spatial exploration;
- any implication that a current Navbar, Dock, rail, drawer or route shell is architecture.

### Preserve as capability/invariant

- one global frame; pages do not create competing global navigation/control systems;
- user can always orient to current identity/context;
- contextual actions reuse canonical capability owners;
- one Raziel, multiple responsive projections;
- ambient signals must come from real state; `HOT / NEW / PROMINENT != TRUE`;
- overlay/clearance/safe-area/focus rules;
- responsive surfaces are one product, not separate architectures;
- rollout safety: do not remove a legacy entry point before replacement parity for the affected audience;
- route/SEO continuity is not silently broken by Shell redesign;
- personal research/saved state is not duplicated by a shell surface.

### 2027 replacement wording

The System Frame becomes an **Adaptive Global Shell** with stable semantic capabilities and flexible placements:

1. Research Context Spine;
2. Global Orientation Header;
3. Global Navigation capability;
4. Adaptive Command Surface;
5. Raziel Companion;
6. Primary Workspace;
7. Contextual Inspector;
8. My Workspace / Personal Attention / Account entry;
9. honest terminal/access states.

Placement is a renderer decision. A desktop Sidebar, top command/header, contextual dock, mobile drawer/sheet or keyboard palette may all project the same navigation/action capabilities. No placement is a second owner.

**Orientation invariant:** location/focus/root/return cannot be silently lost. Direct entry to a Book, Number/Phrase, Post, ELS or other addressable surface remains valid without entering Heichal first.
