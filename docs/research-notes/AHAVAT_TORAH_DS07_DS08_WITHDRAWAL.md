# אהבת תורה — DS-07/DS-08 source adjudication

> Status: 2026-10-22 branch-only research. No database write or deploy.

## DS-07 — withdrawn as a dataset

The low-resolution map described PDF p.78 as a 37-generation Sanhedrin
transmission chain. Direct reading of the page shows a different construction:

> `ומצינו בסנהדרין ל״ז שלשת שורות של תלמידי חכמים יושבים וכל אחד מכיר את מקומו`

`ל״ז` is the daf citation **Sanhedrin 37**, and the counted item in the cited
Mishnah is **three rows of students**. It is not a claim about 37 generations,
links or witnesses. The surrounding passage is ordinary commentary on learning
from every person; no transmission-chain table follows on p.79.

Verdict: the asserted DS-07 population never existed in the source. Keep its ID
only as provenance for the corrected extraction; status
`WITHDRAWN_LOW_RESOLUTION_MISREAD`.

## DS-08 — withdrawn as a dataset

The low-resolution map described PDF p.90 as a bounded Tochecha
blessing/curse word-count comparison. Three later source passes contradict that
description:

- pp.81–90 were read directly; p.89 contains discursive comments on the
  blessings and p.90 discursive comments on the curses, with no count or table.
- p.86 is the separate Har Eival twelve-curses passage, also prose rather than a
  Tochecha count.
- pp.91–99 were searched through the end of the PDF. The sole explicit
  `תוכחה` sighting, at p.98, discusses juxtaposition with the cities-of-refuge
  law and contains no bounded count.

Verdict: there is no source evidence for DS-08 as a numeric dataset. The ID is
retained only as provenance for the refuted p.90 extraction; status
`WITHDRAWN_LOW_RESOLUTION_MISREAD`.

## Consequence

The active inventory now contains eleven source-backed datasets plus two
withdrawn historical IDs. No numerical value is lost: DS-07's real source fact
is the Sanhedrin 37 citation plus three student rows, and DS-08's real material
is the discursive Tochecha commentary at pp.89–90 and p.98.
