## G. Method inventory delta

New method labels justified by the source pass (our research terminology, not Horowitz's):

- **ORDINAL INDEX** — position of a token in an ordered corpus.
- **THEMATIC BOUNDED CORPUS** — define a semantic/entity scope before counting.
- **MULTI-METRIC ENTITY ROW** — preserve occurrence/speech metrics separately from associated word counts.
- **CATEGORY MEMBERSHIP COUNT** — total a semantic category across multiple textual representations.
- **BOUNDED-SPAN AGGREGATE** — define a span, count its tokens, then aggregate a numerical value over the same span.

These extend, rather than replace, the existing ledger inventory: COUNT / CLASSIFY / ORDER / BOUND / AGGREGATE / DECOMPOSE / NORMALIZE / COUNTING REGIME / IDENTITY / POSITIONAL ANALYSIS / CROSS-CHECK / MULTI-PATH CONVERGENCE.
