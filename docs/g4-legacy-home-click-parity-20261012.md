## Suggested order for Home cutover work

1. Make closed Life Journey, Heichal and site Raziel visibly closed in their **actively owned** 2029 Home/Frame surfaces; keep ELS active. Route/server gates in the branch enforce the named locks even before the visual handoff.
2. Preserve exact identity and deep links for root posts, categories, contributor profiles, cipher pages, gallery tabs, forum threads and number pages. Test one populated example of each from a Home click through refresh, auth and return.
3. Decide which Home-specific actions must be in 2029: forum recent/write, gallery Reality/cascade tabs, inline video/story viewing, timeline/anniversary, subscription/push and Dimension Five feed. Put an honest legacy link or closed label on anything deferred.
4. Run the existing automated Legacy↔2029 family parity scan and a real desktop/phone click pass on the exact cutover build. The 2029 Home build flag must be included in that evidence.
