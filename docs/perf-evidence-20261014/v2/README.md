# Isolated experiments, corrected baseline (v2 harness)

Code under test: PR #1092 code tree `0e4e2d57` (docs-only commits on top). Variants are env-gated builds of the same tree: `base`, `narrow` (narrow Home post lists + featured body read separately), `coalesce` (identical in-flight public reads share one request), `cache` (+30 s reuse), `preload` (route chunk modulepreload from <head>).
Raw runs: `iso-d.jsonl` (desktop), `iso-m.jsonl` (mobile), one JSON line per visit; `label` = `cold#n` / `warm#n` (warm = second visit in the same browser context with a real HTTP cache). 5 repetitions per cell, variant and scenario order shuffled per repetition. Summary: `summary-isolated-experiments.txt` (median and range of `ready`).

Conditions: production build served with real gzip (`content-encoding`), immutable assets, `no-cache` html; encoded/decoded bytes come from CDP, not recomputed. Mobile 390x844, CPU x4, 150 ms / 1.6 Mbps. Desktop 1366x768, CPU x1, 40 ms / 10 Mbps. Browser location: Ohio, US; Supabase is in Tokyo. Google Fonts are NOT blocked. Writes and telemetry are refused inside the page (fetch wrapper; no Playwright routing, which would disable the HTTP cache): `link_identity`, `track_visit`, `ingest_event` and the other volatile RPCs; 13 RPCs that are `STABLE` with no DML in the live schema are allowed. `site_flags` is real except on the Number route (mocked open to render the gated page). Real Supabase reads. Content-ready per route: Home = a post link inside `home-composition`; Post = reading stage with >800 chars; World = a topic card or discovery door; Topic = `.sod29-topic-section`; Number = `.sod29-number-page`.

Not measured: a hosted preview, Israel, a real device, a cold Postgres cache. `restReqs` in these files counts every request whose URL contains `/rest/v1/` including CORS preflights (OPTIONS); see v3 files for the method breakdown.
