## שני הממצאים, ומה תוקן

**1. כותרת מתנ״כית מעל גוף אישי נשמרה והוחזרה בלי הסכמה.** „ניתוח הפסוק בראשית ברא אלוהים” מעל „פוטרתי אתמול מהעבודה ואינני מצליח לשלם שכר דירה”. הגוף אינו מתאים לאף תבנית, והסינון אינו הוכחה.
- **היתר השימוש במחקר נשען על מקור מאומת או אישור לרשומה ולתוכנה.** נמחקו שני הנתיבים שנשענו על כותרת ועל מחרוזת `source`.
- **אישור:** סטטוס `approved` / ‏`canonical` שנקבע בעדכון של שורה קיימת. הטריגר כותב קשר (טביעת אצבע של הכותרת, התוכן והנתונים באותו רגע). כל שינוי תוכן אחר כך מבטל את הקשר. הכנסת שורה חדשה לא יכולה לטעון לאישור.
- **טקסט קנוני:** כל שדה לא ריק ברשומה (כותרת, תוכן וכל מחרוזת בתוך `data`) הוא בעצמו ציטוט מפסוק אחד ב־`public.tanach_verses`. ניתוח חופשי אינו מאושר בדרך הזו; הוא דורש אישור.
- **וטו:** פרט אישי שהתבניות מזהות פוסל גם רשומה מאושרת. הוא אינו הוכחה.
- בדיקות: A1, ‏A3c, ‏A3d, ‏A5a, ‏A6, ‏A6c, ‏A6d, ‏Q5.

**2. `fn_personal_memory_erase(..., false)` מחקה מחקר ניטרלי שלא קיבל אישור.**
- **הרשאת שימוש וסיווג למחיקה הופרדו.** ברירת המחדל מוחקת זיכרון אישי בלבד: כל שורה שאינה מסוג מחקר של בוט מחקר, ושורת מחקר שיש בה פרט אישי לפי התבניות. שורת מחקר ניטרלית נשארת, מאושרת או לא. היעדר אישור לקריאה אינו החלטה למחוק.
- `p_include_research_output = true` מוחק גם אותה.
- הייצוא מבחין בין `research_output`, ‏`research_unapproved` ו־`personal_memory`.
- בדיקות: E9, ‏X5, ‏X6.

**מגבלה שנשארת בגלוי:** אמירה אישית שאף תבנית אינה רואה, בתוך שורה מסוג מחקר, **אינה נמחקת במחיקה ברירת המחדל** (רק עם האפשרות המפורשת). זו D-ERASE.
