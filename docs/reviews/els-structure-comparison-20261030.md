## Delivered behavior

Research-only disclosure **מבנים והשוואת מופעים · ללא AI** lazily loads the new presentation. Merely opening Research or the disclosure does not run geometry, load a lexicon, call a model or search for words. Classic/guided hide it; switching Classic/Research preserves already collected comparisons.

Explicit inspection takes the current canonical MATCH occurrence plus selected verified manual finding occurrences (including reversible radius-hidden selections) and selected source sequences. It expands existing hit-key identity into exact positions for the existing `els2029VectorGeometry` owner; it does not calculate matches, scan corpus text or create a geometry engine. It preserves source/ELS/axis distinction, scope/corpus identity and full selected occurrence geometry even when letters extend beyond the current display window.

The panel distinguishes nonzero-offset exact parallel pairs, zero-offset same-line pairs and pairs sharing exact corpus positions. Source rows, same-axis fragments and overlaps do not become independent evidence. No lexical/rarity ranking, significance, strength score or claim of comprehensive discovery is introduced. Unsupported/missing corpus/geometry fails closed. At most 64 selected occurrences and 100 letters per term are accepted; over-limit selection refuses the run rather than silently sampling. Invalid individual coordinates are counted as excluded. Counts cover all admitted pairs; detail lists explicitly display at most 60 pairs each.

Up to three explicitly pinned comparison snapshots preserve origin, current findings/colors, view and window through the existing exact-load adapter. Same snapshot cannot be added twice; different windows/selections are distinct and are not called independent. Opening a snapshot calls the parent's existing research load path and canonical engine re-verification. Manual focus uses the same existing finding selection identity; currently hidden/missing findings cannot be highlighted as present.

This is a **selected-findings structural inspection**, NOT the old broad dictionary discovery scanner, automatic candidate triage, complete motif/corridor/cluster miner, control experiment or all-occurrence batch comparison. Those are still deferred. No disabled pretend controls are added for them.
