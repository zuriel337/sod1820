## הודעה קבועה ושיתוף — בקשת צוריאל האחרונה

הטיקר במעטפת 2029 מציג הודעה אחת ללא החלפה, תנועה או הבהוב:

> האתר מתחדש ונבנה בהדרגה. נתקלתם בתקלה או שיש לכם רעיון לשיפור? עזרו לנו לבנות אותו יחד.

`דיווח או הצעה ←` פותח את ContactGateway הקיים. כתובת המקור נשמרת לאחר
סינון של פרמטרי גישה, זהות, מידע אישי וטקסט חופשי; אין צירוף עיוור של URL.
כפתור `שיתוף` בסרגל התחתון פותח ישירות את ShareActions הקיים: WhatsApp,
Telegram, Facebook והעתקה, ושיתוף המכשיר כשהדפדפן תומך. פתיחת החלונית
אינה שולחת דבר. המסלול הפרטי אינו מקבל קישור ציבורי.

**שליחת דיווח או פנייה אינה פעילה בפריוויו הזה.** הטופס מציג זאת ומאפשר
העתקת טיוטה; הוא אינו מדווח הצלחה מדומה. לא הורחב transport ולא שונה שרת.
ההודעה חלה על דפי SystemFrame; דפי הקמפיין העצמאיים שומרים את עיצובם.
״עכשיו״ והזרם המשותף נשמרו. לא שונה הטיקר של Legacy החי.
