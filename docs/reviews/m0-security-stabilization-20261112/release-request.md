## rollback — סדר מחייב
1. הסרת `world_contributor_research_v2` (ROLLBACK של צעד 11) — **תמיד לפני החזרת האתר**.
2. האתר: ‏`assign_alias` לפריסה שנרשמה בשלב 0.
3. ‏Edge: לפי `edge-rollback/` (מקור זהה / צנזור הערות / שחזור התנהגותי).
4. שאר ה־SQL בסדר הפוך, כל אחד עם קובץ ה־ROLLBACK שלו.
