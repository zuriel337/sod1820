## 2. N6 — היכולות שנכנסות

1. **בקשת ניווט מפורשת בהודעה פרטית נענית בלי מודל.** למשל "תן לי את דף המספר 73", "פתח את העולם", "לינק לדף המספר", "קח אותי לביטויים של המספר הזה". **היום** הבקשה נשלחת ל־`ai-analyze` (מודל בתשלום), והקישור, אם יש, מגיע רק מ־`continuation_href`. **אחרי:** משפט חם ושורה אחת של קישור. ב־trace נרשם `step: navigation`, ‏`model_calls: 0`.
2. **שאלות "איפה" על האתר עונות מתוך רשימה סגורה.** למשל "איפה הקבוצה בוואטסאפ", "תשלח את הלינק לאינסטגרם". הרשימה היא `SITE_LINK_REGISTRY_V1`: עמודי האתר, ועוד ארבעה יעדים חיצוניים מאומתים — קבוצת WhatsApp, ‏Instagram, ‏Facebook ו־TikTok. **יעד סגור** (ארכיון, היכל, "המחקר שלי", "כאן מתחילים") לא מוצע: במקומו נשלחת הסיבה והחלופה הפתוחה שברשימה.
3. **"המספר הזה" — מיקוד מאומת מהשיחה.** כשהבקשה צריכה מספר מההקשר, נקראות עד 16 ההודעות האחרונות **באותה שיחה פרטית**, מ־6 השעות האחרונות, דרך Green API (`getChatHistory`). **זו קריאה חיצונית חדשה.** מספר מתקבל רק משלושה מקורות:
   - מספר שהאדם עצמו הקליד;
   - שאלת גימטריה קצרה, שהערך שלה מחושב ב־`fn_all_methods` (RPC קיים, בלי מודל);
   - קישור קנוני שרזיאל עצמו שלח.

   **הודעה לא קשורה מסיימת את הנושא, והטקסט של רזיאל לעולם אינו מקור.** אם אין מספר מאומת, נשאלת שאלה קצרה: "לאיזה מספר תרצה שאפתח דף?".
4. **מספר בודד מתקבל רק כתשובה לשאלה הזו.** היום הודעה בלי אותיות עבריות נזרקת. אחרי השינוי היא מתקבלת רק אם השאלה של רזיאל היא ההודעה האחרונה לפניה, והמספר בין 1 ל־999999, בלי אפס מוביל. כל מקרה אחר נזרק כמו היום, בלי מודל.
5. **שליחה שנכשלה נכנסת ל־`bot_outbox`** (`enqueueOutbox`, מנגנון קיים). זו כתיבה למסד, באותו נתיב שקיים היום לתשובות.
6. **שום כתובת לא מגיעה מהמודל.** הקישור נבנה מטבלת נתיבים סגורה ומ־`SITE` (`https://sod1820.co.il`). כתובת Preview, ‏http או `localhost` לא נשלחת לעולם.

## 3. N14b — מה נוסף

- **כתיבה:** טבלת הנתיבים מפיקה `/number/<n>`, ולכן הקישור שנשלח בוואטסאפ הוא `https://sod1820.co.il/number/<n>`.
- **קריאה:** `NUMBER_HREF` מקבל את שתי הצורות, באותם גבולות. לכן קישור ישן ששלח רזיאל (`.../2029/number/<n>`) עדיין משמש מיקוד מאומת. היסטוריית השיחה לא נכתבת מחדש.
- **תלות חיה:** `/number/<n>` צריך לעבוד ב־Production, ו־`/2029/number/<n>` צריך להפנות אליו ב־308. הקוד לזה קיים ב־`146f2f0e7`, אבל **לא אומת בחי** (`release-request.md`, שלב 0).

- `node scripts/m0-edge-rollback-assemble.mjs wa-raziel <dir>` בונה מחדש את v21 מ־git (`b4d5ec47` ו־`949c24ad5`). בסבב 4 הורץ שוב: שלושה קבצים, `exact_deployed_bytes: true` לכל אחד. אחר כך פורסים את הקבצים שנבנו, עם אותו entrypoint (`functions/wa-raziel/index.ts`) ו־`verify_jwt=false`.
