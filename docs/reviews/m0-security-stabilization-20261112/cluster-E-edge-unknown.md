## למה contact-notify ב־M0
- טופס יצירת הקשר (`src/lib/supabase.js:1537`) קורא לה אחרי שמירת `contact_messages`. זו כתיבת מוצר נדרשת.
- בלי גבול קצב אפשר להציף את תיבת המנהל ולצרוך את מכסת ספק הדוא״ל. זה משאב בתשלום (§3.4-D).
- הכתובת האישית בקוד היא מידע אישי (§3.4-C). היא תעבור למשתנה סביבה.
