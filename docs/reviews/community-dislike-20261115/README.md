## המימוש

כפתור אגודל מטה ומונה ליד הלייק בהודעות ובתגובות הקהילה הציבוריות, מהארכיון ומ־`community_2029`. משתמשים באותו `ReactionBar`, באותו RPC `toggle_contribution_reaction(uuid,text,text)` ובאותה עמודת `reactions`. המונה החדש הוא `community_dislikes`; הספירות ההיסטוריות `likes` ו־`dislikes` ומערכי האימוג׳י הקיימים אינם נכתבים מחדש. חמש תגובות המחקר הקיימות נשארות לפי הזהות כבעבר.

ה־worker מתיר רק זוג מדויק של 👎 עם `community-repeatable-dislike`, בודק שההודעה נגישה דרך קורא ההקשר הציבורי ומשתמש בהרשאת אורח. ה־RPC עצמו ממשיך לבדוק ולנעול את שרשרת ההורים. הודעה לא ציבורית, מוסתרת, מחוקה או מחוץ לקהילה מסורבת. אין טבלה, הרשאה או מנגנון תגובות נוסף.

המונה מתעדכן מקומית בזמן שמירה, וכשל מחזיר אותו לערך הקודם עם הודעת שגיאה. אחרי תשובת שרת משתמשים במפה שהשרת החזיר; הרענון קורא שוב את הספירה השמורה.
