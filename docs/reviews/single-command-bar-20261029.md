## Result

The normal frame projects five stable entries: Here, Number, existing Raziel,
Now and More. The same composition applies to Posts, Topics, World, Books,
Community, Home, Number, Journey and Heichal. Device-specific global navigation
remains available through the existing header/sidebar/drawer.

- Here opens the existing Context sheet with its actual section map, source
  context and the existing research trail. A slender progress cue sits inside
  the Here entry only when real sections and an active section are supplied.
- Number opens the existing Number capability, retaining explicit
  expression/method/result focus. Its existing maintenance lock is enforced by
  both the launcher and the capability projection; no invented default value.
- Raziel keeps its current provider/session and desktop/mobile projection.
  Merely opening or navigating never invokes a model.
- Now opens the existing Attention projection and its World/For me/Raziel
  entries. A genuine unread count belongs on this entry instead of a separate
  floating update chip.
- More contains existing contextual actions and research tools, plus Search.
  Inspect, source sharing and save actions remain under their existing
  projections and permission boundaries; no unsupported follow/write action
  is invented or enabled. Existing inline content links and section navigation
  remain in their pages.

The separate floating locator/mobile context cue is suppressed while the shared
frame is present; its section map remains reachable in Here. The standalone
selection launcher is folded into More while its selected target is retained.
The extra fixed unread chip is replaced by Now/System badges. Existing static
in-content navigation is not removed.

Tool Mode keeps the registered tool's four actions, shared Raziel and System
entry in the same physical dock. System enters the five-entry bar; More returns
to the registered tool. No tool engine, input, result or registration lease is
reimplemented. Number remains a capability launcher, not a separate owner.

Sheet-to-sheet navigation retains the persistent entry for focus restoration;
an inner button that disappears is not saved as the return target.
