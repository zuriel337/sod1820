## הרשאות ונתונים חיים

בענף הפריוויו הזה בלבד נוספה תקרה מצמצמת דרך MaintenanceLock הקיים: רזיאל ומסע החיים נעולים לציבור; הצופן למנהל מאומת בלבד. מצב הרשאה שטרם נטען נשאר חסום. פרוקסי רזיאל מאמת JWT ותפקיד בשרת לפני קריאת מודל; `user_metadata.role` אינו סמכות. נשמרו זהות, מגבלות העלות והיעדר ניסיון מודל אוטומטי נוסף.

לא שונו `site_flags`, הגדרות Auth, מסד, Edge Functions או הרשאות משותפות. ה־worker לענף החדש זהה בבייטים ל־worker המאושר של הבסיס; ה־workers הקודמים לא הורחבו. חסימות Production והגבלת הענפים המדויקת נבדקו גם בשלילה.

הפריוויו ממשיך להשתמש בשירותים החיים: פעולות מורשות באזור האישי, שמירות, קהילה ומדיה אישית עשויות לכתוב לנתונים חיים לפי ההרשאות הקיימות. פעולות מודל/צופן מפורשות של מנהל כפופות לשרת ולעלות הקיימים. **הבדיקות לא ביצעו כתיבות מוצר, העלאות, דיוור, התחברות לחשבון חי או קריאות מודל.**
