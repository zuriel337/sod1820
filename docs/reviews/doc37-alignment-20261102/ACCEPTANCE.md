## מעבר וחזרה

אין main merge/push, שינוי דומיינים, alias או 2029 cutover. Legacy `/` נשאר באתר החי. תוצר הפרסום העתידי משתמש בבעלים הקיימים לכתובות ישנות/חדשות, canonical, XML/robots ודפי שירות; HTML/API/worker הם no-store, assets בעלי hash ניתנים למטמון. הפעלתו המתארחת חסומה במפורש.

לפני מעבר: לסגור את חסמי המוצר, לשחזר סט DB+מדיה אמיתי ביעד מאושר, לקבל את תצורת התוצר המתארחת, לאמת שוב aliases/נעילות, ואז לקבל אישור 2029 Production cutover עםSHA ו־deploymentID. אין החלפת דגלי Production כדי לחקות את הפריוויו.

חזרת אתר: החזרת התעבורה לפריסת Legacy המאושרת שאומתה באותו מועד, ועדכון worker באותוscope לבייטים המקוריים; לבדוק לשוניות חוזרות וחדשות. בדיקת lifecycle מקומית קיימת ואינה rollback שבוצע בחי. חזרת אתר **אינה** שחזור DB או מדיה; נתוני הרשמה/הסרה/מחקר אינם נמחקים כחלק ממנה.

המועמד מיועד לקבלה מוגנת, לא לאישור אוטומטי לעלייה. מסמך37 יעודכן בתוספת עובדתית, בהפרדה בין תוכנן, מומש, נבדק ועלה לשרת המשותף/לאתר.
