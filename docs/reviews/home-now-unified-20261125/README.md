## 3. העיצוב המוצע (ראו `preview.html`)

**א. דף הבית — «עדכונים אחרונים» (ראש תוכן הבית)**
- אזור אחד, חי, **בלי נעיצות ובלי קדימות מלאכותית**. מקור הנתונים: אותו קורא זרם יחיד.
- **מחשב:** שתי עמודות. ימין: עדכוני האתר עצמו בסדר כרונולוגי (פוסטים חדשים ועדכוני `site-news`). שמאל: הפריט האחרון מכל מקור ציבורי מורשה (זרם המציאות, אור הגאולה, גילוי יומי/קבוצות וכותבים, ערוצים). **פריט אחד לכל מקור**, מתעדכן מעצמו כשמגיע פרסום חדש.
- **טלפון (הבהרה 25.11.2026):** שתי העמודות מאוחדות ל**רשימה כרונולוגית אחת**, מהחדש לישן, ללא נעיצות וללא קדימות לפי סוג תוכן. פרסום ציבורי אחרון, למשל תמונה שהועלתה לזרם המציאות, עולה לראש הרשימה עם תמונה ממוזערת. **במחשב** נשמרות שתי העמודות. אותו מערך נתונים והחלוקה לתצוגות היא טהורה בצד הלקוח (בלי קריאה נוספת).
- כל שורה: תמונה ממוזערת (לא באור הגאולה, לפי הכלל הקיים), מקור, זמן יחסי («לפני X», בבית בלבד), סוג, כותרת ותקציר בשורה אחת. סרטונים: נגן לפי דרישה בלבד, בלי ניגון אוטומטי ובלי טעינה מוקדמת.
- שורות עד ~56px, בלי «קומות» לפריט בודד (חוק שורה מלאה). מפת המציאות נשארת סדרת הדגל באזור שלה ואינה מקבלת עדיפות בזרם.

**ב. «עכשיו» — מרכז עדכונים בשרשורים**
- **שרשור לכל מקור**: בראשו העדכון האחרון; הרחבה פותחת פרסומים קודמים (נטענים רק בהרחבה). **המקור שהתעדכן לאחרונה עולה לראש הרשימה** (המקורות ממוינים לפי זמן העדכון האחרון).
- מתג **«לפי מקורות / הכול · כרונולוגי»**; בורר מקור (קבוצה / ערוץ / סדרה / אתר, לפי מפתח יציב, כבר קיים).
- הודעות ותגובות של אותו **שרשור מוכח** (שורש + תגובות מאושרות) מוצגות יחד תחת השורש. אין חשיפת הודעות פרטיות, תגובות שטרם אושרו או חומר לא מורשה.
- זהות מקור, כותב, תאריך (עברי+לועזי לפי חוק הזמן v4), «חדש» (לפי מצב «נראה» לכל צופה) וקישור מדויק נשמרים. סימון «חדש» הוא סימן בלבד, לא קדימות.

**ג. הודעת בנייה והרשמה (אחידה בשני המקומות)**
- אותו נוסח מדויק וכפתור «הרשמה לעדכונים», כשורת תחתית דקה של כל אזור (לא בראש, כדי לא לדחוק את התוכן מתחת לקפל במובייל; HOME-04).
- הכפתור פותח את `NewsletterSignup2029` הקיים (מוצר «עדכוני האתר», `submitNewsletterSignup`), לפי `subscription_funnel_law` v22. אין מנגנון הרשמה שני. הצלחה תוצג **רק** אחרי תוצאה אמיתית מהשרת; כשהמסלול אינו זמין (`newsletter-purpose-unavailable`) תוצג הודעה כנה.

**ד. עיצוב (עודכן 25.11.2026, Design V2 §14.12):** האזור האישי הוא תקן הייחוס. התצוגה המקדימה נבנתה מחדש **רק על רכיבי Royal 2029 הקיימים** (`royal2029.css` + `personalArea2029.css`, בלי שינוי), עם ערכי הצבע מ־`paletteTokens2029.js`: `.r29-hall`, `.r29-card`, `.r29-medal`, `.r29-badge`, `.r29-chip`, `.r29-btn`, `.r29-rule`. הבית הוא חזית (רויאל כחול וזהב); «עכשיו» הוא פאנל מסגרת ושומר על זהות הסרגלים והפאנלים; דוגמת הפנים (חום וזהב) מקורבת בגוון הזהב הקיים בלבד. הגרסה הקודמת של התצוגה, שהכילה CSS שהמצאתי, הוחלפה. בדיקות ערכות: `preview-day.html` ו־`preview-parchment.html` (צילומי נייד).
