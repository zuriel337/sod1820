A2 חל רק על חשבון Auth חדש מזמן הפעלה קבוע ומתועד, ורק לאחר אימות המייל בשרת. הוא חל על הרשמות חדשות גם דרך Legacy. כניסה לחשבון קיים, רענון, שינוי כתובת והיסטוריה אינם מצרפים. לכתובת חדשה נרשמת רק site-updates; לכתובת פעילה קיימת אפשר להוסיף רק אותה תוך שימור השאר. כתובת שהוסרה/אינה פעילה נשארת ללא שינוי. אין Follow,Push,WhatsApp,visitor,קרדיטים,חיוב או קמפיין.

**תנאי הפעלה שאינו פתור עדיין:** Auth משותף, ובלגאסי החי עדיין אין את נוסח ברירת המחדל החדש. אין להפעילA2 לפני שהנוסח נכון בכל נקודת הרשמה חדשה פעילה. [נוסח ומקומות החיבור](auth-copy.proposed.md). הכנת הנוסח בענף אינה פריסתLegacy. הפעלת הרשמה חדשה/OAuth בפריוויו נעשית רק לאחר קבלת השרת וה־callback המדויק; כניסה קיימת נשארת זמינה. אין לשנות SiteURL או להרחיב wildcard.

סדר ההפעלה לאחר אישור: רענון בעלויות/hash/סכמה → D → B וה־signup Edge → קבלת החוזה/שלילות ללא משלוח → נוסח נכון בכל signup פעיל → A2 האטומי והוכחת cutoff/hash → פתיחת נתיבי הלקוח הקיימים בלבד → קבלת בעל חשבון אמיתית. אם אחד התנאים אינו מתקיים, לא מפעילים את השלב התלוי בו. אין אישור לשלוח מייל בדיקה, ליצור חשבון אמיתי, להפעיל קמפייןC או להעביר2029 לחי במסגרת החבילה.
