## השלמות הבעלים — במקום בקשות מפוזרות

- **B — חיבור טופס "עדכוני האתר":** שדה ואילוץ באותה טבלת מנויים ופריסת newsletter-signup הקיימת למטרה site-updates. אין רשימה חדשה, שינוי מנויים/הסרות ישנים או הרחבת הסכמות opening-only.
- **D — תיקון אישור הסרה:** פריסת handler ההסרה שנבדק, כך שהצלחה מוצגת רק לאחר שמירה או הוכחה שהכתובת כבר הוסרה. חתימות וקישורים קיימים נשמרים. כשל לא יוצג כהצלחה.
- B/D ממתינים לאישור התשתית המפורט ב־[בקשה הקיימת](../../../../../signup-default-updates/APPROVAL.md). אין צורך בשינוי A2 כעת, ואין בקשת קמפיין או משלוח בדיקה.
- Google/Facebook: לוודא רק callback קבוע ברשימת Redirect URLs, ואז בדיקת כניסה של הבעלים. אין שינוי Site URL או כתובות קיימות. זהו צעד שנדחה בידי צוריאל, לא כשל בסיסי בספקים.
- בקרת מנהל: כניסה לחשבון המנהל הקיים, רענון ופתיחת trace קיים בלבד, בלי מודל/כתיבה/חיוב. קבלת שני החשבונות והפעולות האישיות כבר הושלמה.
- תוצר Production מוגן: קודם מסלול מאומת ללא שיוך דומיינים והרשאת יצירה נפרדת; אחר כך קבלת התוצר המדויק; אישור cutover סופי יהיה נפרד עם SHA ו־deployment.
