## Design

The existing global Provider already survives route changes. Read its active turn
and completed thread rather than starting another poller/store. The existing Orb
shows scan presence; opening it displays observed elapsed time and status, explicit
cancel and return. No percentage or invented provider progress. A route-state turn
ID resolves only against the current session; coordinates/phrase/tokens never go
into the URL. The existing canonical engine verifies the return load as usual.

## Limits

Ordinary Raziel conversation remains busy during collection. Navigation is usable;
concurrent conversations are not introduced. Reload does not auto-resume a scan;
the existing explicit recovery remains. Route state with no current session cannot
restore the private occurrence. This is not a persistent global jobs inbox or a
collection scheduler. No live model or live Preview acceptance is claimed.

Return restores the exact axis through the existing engine load contract; it does
not reconstruct an unsaved native viewport, zoom or manual-finding edit session.
The existing saved-cipher workflow remains the owner of those saved settings.
