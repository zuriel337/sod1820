# תגובות לפוסטים ותרומות באזור האישי — 2026-10-26

## תוצאה

הכרטיס „תגובות אליי” ב־My Workspace מבהיר כעת שהוא כולל שני סוגים נפרדים:

- תגובות לפוסטים ולתגובות בקהילה, כולל הצ׳אט הוותיק (`openweb`).
- תגובות לתרומות מחקריות.

כל רשומה מסומנת לפי מקורה. תגובת קהילה נפתחת בקורא הקהילה החי של 2029 דרך `/2029?preview=community&data=live`, טוענת את שורש השרשור ואת נתיב ההורים הדרוש בלבד, ממקדת את התגובה ומספקת חזרה מדויקת אל `/2029/me/messages`. הבחירה בנתיב 2029 מבטיחה שגם Reload נטען מאותו runtime קיים, בלי להוסיף rewrite חדש.

## בעלות על היסטוריה ישנה

ה־RPC הקיים `replies_to_me` הורחב כדי לזהות בעלות היסטורית רק באחד משלושה מסלולים קנוניים בצד השרת:

1. `research_contributions.author_user_id = auth.uid()`.
2. `contributors.user_id = auth.uid()` עבור `author_contributor_id` מדויק.
3. קישור Contributor מאושר דרך `identity_edges(kind='legacy_seed')` אל Person יחיד שב־`persons.account_user_id = auth.uid()`.

אין התאמה לפי שם, כינוי, דוא״ל, טקסט, פרמטר URL או מיפוי לקוח. תגובות של המשתמש עצמו מוחרגות גם כשבעלותן הגיעה דרך Contributor או Person.

## מצב הנתונים החיים

סריקה מצרפית בקריאה בלבד מצאה:

- 6,547 הודעות שורש ישנות מ־OpenWeb.
- 18,977 תגובות ישנות.
- 0 הודעות שורש ישנות שמחוברות כיום לחשבון דרך בעלות קנונית.
- 0 שורות OpenWeb שמחוברות כיום ל־Account Person דרך קישור Contributor מאושר.

לכן הקוד מוכן להציג שרשורים ישנים, אך בחשבונות החיים הם יתחילו להופיע רק לאחר תביעת הפרופיל הישן או חיבור Human-Gate מאומת. המיגרציה שבחתך זה לא בוצעה במסד חי.

## גבולות פרטיות

- קורא ההודעות האישיות נשאר owner-only ומותר ל־`authenticated` בלבד.
- קישור מהאזור האישי פותח רק שורש ותגובות במצב `approved` וממקורות הקהילה הציבוריים.
- שרשור פרטי, מוסתר, דחוי או לא קיים אינו מוחזר על ידי קוראי הקהילה.
- אין API, inbox, Provider, store או טבלת זהות חדשים.

## אימות

- 11 בדיקות Node ממוקדות לקוראי הקהילה, לקישור המדויק ולחוזה הבעלות.
- בדיקת Chromium על הודעת OpenWeb משנת 2016 ברוחב 320, 390 ו־1440 פיקסלים: תגובת המקור ממוקדת גם אחרי Reload, החזרה מדויקת, אין גלישה אופקית ואין קריאת מודל.
- מטריצת האזור האישי הקיימת: 72 מצבי viewport/theme/module, כולל מודול ההודעות.
- `npm run build:2029`, חסם dependency graph, בידוד 2029, cheap hardening, System Frame, My Workspace ו־Legacy Production Lock.

הראיות המקומיות נמצאות ב־`docs/reviews/personal-replies-community-evidence-20261026/`.
