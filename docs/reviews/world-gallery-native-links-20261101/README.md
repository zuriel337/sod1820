## התקלה והתיקון

המקור המשותף של הקישורים היה `topicSourceContext.reopen.galleries`: הוא המשיך
לייצר `/archive?tab=galleries&gal=...`. השימוש בקורא החדש אינו מוגבל עוד לגלריות
פיילוט; `gallerySourceHref2029` הקיים כבר תומך בכל מזהה גלריה תקין.

כעת כל הופעת מקור מקבלת כתובת native עם **מזהה הגלריה והתמונה המדויקים**:
`/world?view=gallery&gallery=54&image=...#gallery-source-...`.
הכתובת הישנה נשמרת ב־`legacyHref` לצורך שימור המקור, ואינה משמשת קישור ניווט.
הקורא הציבורי הקיים בודק מחדש את זכאות התמונה ביעד; הכתובת אינה הרשאה.
