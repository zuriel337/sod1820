- אין בדיקה על טלפון אמיתי (ולא Safari/iOS). כל נתוני הביצועים מ־GL תוכנה.

## 6. חזון המסעות במסך מלא (בלי לבנות חדרים)
הסצנה היא "סצנת ממצא" ניתנת להטמעה: כל הקלט בפרופס — נתונים (`spec, paths, value, verifiedCount, total`), בחירה (`focusIndex, onSelect`), מצב (`view, explode, spin, layers, resetToken`), הצגה (`look, quality, glyphs3D, reducedMotion`), מחזור חיים (`onFallback`). היא ממלאת את מיכל ההורה (המצלמה מותאמת ליחס המיכל, ללא תלות במידות העמוד), מחזיקה בעצמה את ה־GPU context ומשחררת אותו, ונעצרת מחוץ למסך. חדר במסע יוכל לעטוף אותה במיכל מסך מלא ולהעביר `look` משלו — ללא שכפול גימטריה, מודלים או חוזים. לא נבנתה מערכת חדרים.

1. אישור כיוון (או שילוב B+A+C כפי שהוצע) — רק אחרי בדיקה על טלפון אמיתי.

4. החלטה: האם לפתוח את רזיאל לאורחים; ואם לדחות את שלד ה־DOM של הכיוונים ל־lazy.
