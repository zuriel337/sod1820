# הגילוי היומי · שרשור בקהילה והקרנה ל״עכשיו״

החלטת מוצר מ־13.11.2026. המפרט משלים את מוסכמות הפרסום, קודקס הקליטה ומסמך 37. שלושת הסעיפים מוצעים להפעלה באמצעות `apply_contracts.sql`.

## קבלת החוזים

- [ ] פרסום ציבורי משויך לחשבון הקהילה המאושר, שם התצוגה `sod1820`. קרדיט לדברי מקור נשמר בתוך ההודעה. שם אישי, כתובת כניסה ופרטי תפוצה אינם מגיעים לתוצר ציבורי או לקישורי שיתוף.
- [ ] לפני הרצה, בדיקת שלושת ה־MD5 על היעד. הקובץ מחיל תוספות אטומיות בלבד. הרצה חוזרת עם אותם ערכים לא תכתוב דבר. סטייה באחד מהחוזים מבטלת את העסקה כולה. קובץ החזרה שומר כל שינוי מאוחר באמצעות עצירה במקרה של סטייה.
- [ ] אחרי ההחלה, משווים את שלושת ה־MD5 לרשימה שבהצעה. גרסאות החוקים ב־`nodes` נשארות מקור הסמכות לגבולות האמת, הזהות והשחרור.

## קבלת המימוש

1. **קהילה.** שורש אחד דרך החשבון המאושר. שומרים ארבע הודעות מייל מ־12.11 בשעון ישראל, יחד עם ההודעות הרלוונטיות של הקבוצה מאותו תאריך. מייל: 2↳1, 3↳2, 4↳3. שני מקורות ל־1158, הודעה אחת. קישור לחשבון אמיתי נבדק בנפרד מקרדיט טקסט. ייבוא חוזר שומר את אותם מזהי שרשור והודעות ומונע התראות עבר.
2. **חשיפת מקור.** גוף, קרדיט ושעה ברירת מחדל. פתיחת ״פרטי הודעה״ מציגה רק סוג מקור ומקור ציבורי מותר, ובמקרה של שני מקורות מציגה את שניהם. בדיקה בנייד ובמחשב, כולל קורא מסך ופתיחה במקלדת. מוודאים שפרטי הכניסה, התפוצה וקישורי המייל הפרטיים אינם עוברים בתגובת השרת, בקישורי שיתוף או בהודעה לקבוצה.
3. **עכשיו.** פריט יחיד תחת `group:gilui-yomi`, עם ״לדיון בקהילה״. בדיקה ב״הכול״ ובמסנן הקבוצה. אותו שורש ואותו מזהה אחרי עדכון מהותי. הודעות המקור ששויכו לדיון מוצגות בתוך השרשור. מקורות אחרים בקבוצה מופיעים כרגיל.
4. **וואטסאפ.** הודעת בדיקה אחת לקבוצה עם קרדיט, טקסט מאושר וקישור ישיר. שומרים מזהה שליחה ומוודאים מסירה לפני שמסמנים הצלחה. תגובה אחת מצוטטת מגיעה להורה הנכון בקהילה בדיוק פעם אחת. תוכן שנשלח בידי המערכת אינו חוזר כתגובה חדשה. הורה חסר ממתין לבדיקה.
5. **מייל.** עדכונים לנמענים שבחרו לקבלם. תוכן חדש דורש מסלול זיהוי והחלטת חשיפה. כותרות ההורה נשמרות, והודעות שאינן בשרשור אינן מיובאות.
6. **סדר עבודה.** ייבוא מבוקר וקבלה בקהילה, היטל באותו קורא של ״עכשיו״, ואז בדיקת השיתוף והתגובה בקבוצה. פרטי המקור נשמרים בקליטה הקיימת. לשרשור אין עותק נוסף בפיד או במאגר מחקר.

## בדיקות שבוצעו להכנת ההצעה

מזהי שלושת חוזי הקודקס, תוכנם הרלוונטי וחשבון הקהילה נבדקו בקריאה. נבדקו ערכי ה־MD5 של הנוסח הקיים ושל הנוסח לאחר צירוף כל סעיף, באותה פונקציית PostgreSQL שבה משתמשת ההצעה. ייבוא, שיתוף, קבלה בדפדפן והפעלת SQL כותב ממתינים לשלב ההפעלה.
