## 3. מה חסום היום מאינדוקס

- **מספרים:** רק 450 מספרים פתוחים (`sitemap_numbers`). 1,275 מספרים עם ביטוי מאומת חסומים (820 עם 3 ומעלה), וגם 48 מספרים שמופיעים בכותרת פוסט (78, 787). המספרים 1–9 חסומים תמיד. הכלל סופר גם ביטויים לא מאומתים. הצעה מוכנה, **לא הוחלה:** `supabase/proposed/indexing-audit-20261120/sitemap_numbers.after.sql`. לפי בדיקת קריאה: 450 ← 1,294 מספרים, ואף מספר לא יוצא.
- **בית המדרש:** `/beit-midrash` וכל דפי השיטות הם `noindex, nofollow`, קבוע ב־`api/og.js`. דורש החלטה.
- **תוצאות מחשבון** (`/gematria?q=…`): noindex. נכון (יכול להכיל שמות פרטיים).
- **אזורים "בבנייה"** (`/heichal`, `/cross`, `/name`, `/archive`): 503 עם Retry-After. מכוון, אבל `/archive` כבר מדווח ב־Search Console כשגיאת שרת.
