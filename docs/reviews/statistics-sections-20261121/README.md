- **הריבוע הכללי ירד** מדף הבית, מהעולם, מדף המספר, מהצופן התנ״כי ומהספרייה. הוא נשאר רק ב"עכשיו" (מגירת המסגרת), עם תיקון גודל האותיות בכרטיס ועם קישור ל־`/stats`. מדפי המחשבון ומדף הפוסט הוא ירד בענף של #1463, לפי חלוקת הכותבים.

  - בצופן התנ״כי ובצפנים: חיפושים, צפנים שפורסמו, צפנים חדשים וצפיות במדור.
