Source: the foundation closure list of PR #1321 (`docs/reviews/m0-security-stabilization-20261112/foundation-closure-list.md` at `4a406fed2`:
sections 6.4, 7.2, 10.1 and the rows B5, B13, B14, CL-06, CL-07, CL-11, CL-12, CL-16) and the acceptance matrix of the contract handoff
(`origin/claude/laws-alignment-20261112` @ `53bb72e13`, `README.md` section 13.1). The closure list itself was **not** extracted (it is a
planning document of the frozen pull request); this file keeps only what bears on enforcement. **No new rule system is built to close any of
these**: the task was to extract, review and document. Each row says what is missing, the current state, and what would close it.
