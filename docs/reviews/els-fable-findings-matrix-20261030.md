- Reuse the existing global session's structured completed reading. No new AI call,
  query, scan, dictionary, engine, transport, Provider, product write or server deployment.
- All valid receipt-backed findings receive an automatic, hideable matrix overlay.
  Selection focuses the exact replay coordinates, including backwards readings.
  Existing primary-axis and manual-finding marks/identities remain unchanged.
- The card lists all findings independently of the manual 12-term limit. The rail
  counter distinguishes manual results from AI results. Selection does not add a
  word to the manual scanner or initiate another search.
- Word boundaries are displayed only when the model's supplied parts concatenate
  to the original normalized letters. Final letter forms are presentation only.
  The original sequence stays visible. No missing letters or words are supplied.
- A receipt wholly contained in the selected axis is labeled an axis fragment,
  not a newly discovered crossing. This is coordinate-based, with no Golden rule.
- Receipt identity, corpus and selected occurrence must agree. Current visible
  letters must also agree before painting. Incomplete results, wrong occurrence,
  missing/mismatched receipts and conflicting letters never receive an overlay.
- The existing explicit conversation save/restore retains the structured result;
  the overlay is re-derived, not persisted in a second store. Camera mode hides
  the overlay rather than mixing it into its existing admitted-finding sequence.
