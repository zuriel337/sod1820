1. **לפי החלטת צוריאל: שינויי השרת ממתינים.** לא הוחלו SQL, Edge או הגדרות Auth. `newsletter-signup` גרסה 19 ו־`send-newsletter` גרסה 16 נשמרו. ההצעה המדויקת והחזרה נשמרו ב־`b21ed1ff399e86e1aed4d97f8eccda0954f1ff23`.

3. גישת מנהל נבדקה בזהויות מבוקרות ובשלילות שרת; כניסה אמיתית, יציאה/החלפת חשבון ופעולות מכוונות עם החשבון שלך עדיין דורשות קבלה. לא הופעלו מודל, חיוב, העלאה, שמירה, מייל או פרסום חי בבדיקות.
4. כשל ההסרה החתומה שתועד קודם נשאר פתוח ונפרד. הסרת הקישור מכרטיס הבית אינה הסרת מנגנון ההסרה או שינוי suppression.
5. קבלת H1 ההיסטורית נשמרת. עדכניות הגיבוי הנוכחי וכיסוי bytes של מדיה עדיין דורשים הוכחה; חזרת אתר/SW אינה שחזור מסד ומדיה.
6. התאמת הפעלת Production ואישור cutover מדויק נשארים נפרדים. `main` נשאר `2195c9784c5c9f0b1ec3cd3c1137fbd76045845b`; האתר החי נשאר Legacy `dpl_BFpwZGiYL3Qpdy9nCuGKGb9Xmko2` / `d1837efcf5a978d10a514010f3695680f231e116`.
