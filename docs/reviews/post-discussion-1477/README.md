# דיון פוסט לפי מזהה קנוני · #1477

## מה קיים בשרת

קריאה בלבד בשרת החי אישרה ש־`post_conversation_projection(p_post_wp_id, p_limit)` ו־`add_contribution` קיימים. לבחירות #5107 ולבנט #5113 אין `wp_id`. הקורא הוותיק מתחיל בחיפוש לפי `wp_id`, ולכן אינו יכול להציג תרומות מקומיות בשני הפוסטים האלה. פרסום מהכותב הרגיל בקהילה מסווג תחת `home/community`. הגבלת התעבורה של הקריאה הציבורית מכירה במסלול הזה בלבד לכתיבת תגובה בקהילה.

## הצעת שרת לבדיקה

הקובץ [post_discussion_canonical_v1.sql](../../../supabase/proposed/post_discussion_canonical_v1.sql) נמצא ב־`supabase/proposed`.

- כותב הדיון מקבל `posts.id`, מזהה יחידה אופציונלי וטקסט. הוא דורש חשבון, בודק שהפוסט ציבורי ושהיחידה שייכת למקור, ומשתמש ב־`add_contribution` הקיים עם `target_type='post'` ו־`target_id=posts.id`. מזהה היחידה נשמר בשדה נפרד באותה עסקה.
- הקורא מקבל `posts.id` ומאחד את התרומות המאושרות לפוסט עם תגובות WordPress במצב `publish` דרך `wp_id` של אותה רשומה. תגובות ותיקות נשארות במקור, עם מזהה המקור וקישור ההורה. ה־RPC הוותיק נשמר לתאימות.
- ממשק הבדיקה מורכב פעם אחת בתחתית הפוסט. לחיצה ליד יחידה מקבעת את היעד בטיוטה עד שליחה או ביטול. הקישור בתגובה מופק באמצעות `publicPostUnitHref`. הממשק מופעל ב־Vite במצב פיתוח עם `VITE_POST_DISCUSSION_REVIEW=true`.

## ראיות בדיקה מקומית

PostgreSQL 17 בקונטיינר חד־פעמי השתמש בסכמת fixture ובמימושים הקיימים של `add_contribution`, ‏`research_state_apply_ops_v1` ו־`research_state_snapshot_v1`. אפשר להריץ מול מסד ריק ומבודד עם `psql -X -f scripts/test-post-discussion-review.sql`. הבדיקה כוללת ארכיון ותרומה מקומית באותה רשימת דיון, חסימת תגובה אנונימית, בידוד פוסט מוסתר, דחיית יחידה מפוסט אחר ושמירה לפי זהות חשבון.

ב־Chromium ב־390 וב־1440 פיקסלים, דף בנט נבנה מנתוני fixture עם מזהי הפוסט והיחידה של המסירה. מתאם HTTP מקומי הפעיל את פונקציות PostgreSQL. הלחיצה ליד ״ברית מלח״ פתחה טיוטה, הגלילה עברה ליחידה אחרת, והשליחה החזירה שורה לדיון היחיד. ״חזרה ליחידה״ נתן מיקוד לעוגן המקורי. התגובה נשארה אחרי רענון, והשמירה נקראה מה־snapshot בחיבור נפרד. מתאם הבדיקה מדמה את שכבת Auth/REST. האחסון, הפרסום והקריאה ב־SQL רצו על שרת PostgreSQL אמיתי.
