words, topics and information as well as numbers. Older automatically created
topic cards are not a competing tree. Preserve their material and addresses;
do not delete them or infer a verified edge from a matching word, writer, title
or number. A source, its attribution, an approved finding and a tree connection
remain distinguishable. Relevant prior receipts include
`zvi-world-source-tree-number-integration-20261030.md`, the public World

## Bounded implementation

- The existing World sources view presents topic and source cards together,
  with one URL-preserving search and an optional writer filter. Existing source
  and topic identities and URLs remain intact. A search term can match a topic's
  public search terms even when it is not a number; local topic and group-text
  matching also ignores Hebrew vowel marks.
- After an explicit text search, the existing public readers search an
  eight-post page of the `סוד החשמל` corpus, a 40-row window from the existing
  redacted group-source reader, and paginated eligible public findings. The UI
  states when this is partial and allows more results. Content searches are not
  a complete search over all writers, all historical pages or the graph.
- Identical complete finding statements are grouped only for display, retaining
  every finding and eligible source link. Identical non-truncated redacted group
  messages from the same source writer are similarly grouped with their separate
  occurrences. These groups do not claim identity of the underlying works or
  create canonical graph edges. A group occurrence receives an exact link only
  when the anonymous public source and expected contributor were independently
  admitted; otherwise the already-admitted redacted message is readable in
  place without a fabricated source link.
- The public activity card opens an existing redacted group message inline. An
  exact shared group anchor is rendered even when the occurrence is beyond the
  initial visible page. A change of writer removes an old unrelated source
  reference and source-occurrence anchor.

## Remaining work and boundaries

The 78 topics still need evidence-based reconciliation to their source material,
including unique fragments and occurrences, before any claim of complete
deduplication or coverage. Search does not automatically build the tree. Some
corpus searches are exact-text database matches and may miss alternate Hebrew
spellings, markup or vowel forms. An absent match is not proof of absence.

The local browser fixture uses synthetic public data and intercepted network;
it is not a test of a signed-in account or the live material end to end. No
product data, RLS, source-proof policy, engine, public routes, preview
permissions, production configuration or site deployment is changed here.
The public message reader's existing proof, redaction and eligibility rules
remain authoritative. Preview, end-to-end acceptance, and the previously open
Isolation and gallery issues require separate verification.
