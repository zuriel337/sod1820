## 2. התאמת ai-analyze לחוזה המאוחד

- השרת החי v90 הורד לקריאה בלבד, verify_jwt=true. קובץ החזרה המדויק הוא rollback-ai-analyze-v90.ts, SHA256 `fc1f5e3afce9a46332e36ecb0f66801c3d1d5d87b31bf369c0df47f01af7ff96`.
- הקובץ המוצע הוא ai-analyze.proposed.ts, SHA256 `2ac19e112e77e71fbab61270338e126edf88128a786f3425b09157291494281f`. זהו bundle מוכח של16 מקורות קנוניים בענף המוצר, ב־ce080696 (ממשיך c2f2e994); לא ייבוא מחדש של ענף. provenance מצורף. JWT, זיהוי אדם, שער יכולות, תקציב, פרטיות, התאמת מופע, קבלות עבודה ו־idempotency נשמרים.
- תוספת שרת מפורשת: אימות חתימת RS256 דרך JWKS הקבוע של Vercel, עם issuer/team, audience, project ו־subject של סביבת Preview בלבד; JWT משתמש Supabase מאומת נדרש בנפרד. רק עבור זהות שרת זו, שער זמינות האתר אינו קורא את lock_raziel_site, ויכולת פייבל מופעלת כברירת מחדל בפריוויו אלא אם הוגדר OFF מפורש. זה אינו מעניק role, מנהל, קרדיטים או פטור ממכסה. פייבל נשאר מנהל בלבד, עם הסכמה לעלות וקבלות/idempotency. Production ו־WhatsApp שומרים את מסלולם. אין שינוי flag משותף ואין מפתח חדש.
