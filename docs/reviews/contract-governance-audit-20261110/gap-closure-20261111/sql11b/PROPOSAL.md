## מה משתנה

- **הטקסט:** הבנייה היא `npm ci` + ‏`npm run build` + שערי ה־CI, בלי Legacy. שחרור רק באישור מפורש.

- **`dispatch_context`:** אותן ראיות כמו קודם (suggestion_id, ‏package, ‏current, ‏latest, ‏delta, ההחלטה). נוספו: `activation=NOT_ACTIVATED`, מה נדרש להפעלה ולשחרור, `intended_scope`, ו־`auto_maintenance=false`.

- **תחום הכותב:** הרשומה לא תופסת אותו. `assignment_scope` מקבל את ה־task_key (ברירת המחדל של הטריגר), ולא את `dependency-maintenance:runtime-packages` (N11).
