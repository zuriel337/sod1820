## גבולות הבדיקה

מדידות הפריוויו משתמשות ב־Service Worker האמיתי ובנתונים ציבוריים אמיתיים.
אין החלפת תגובות רשת או יירוט לצורכי מדידה; חסם עצמאי דוחה כתיבות,

המקומיות משתמשות בנתוני בדיקה והן מסומנות בנפרד. ניסוי ה־Topic delay

מדדי קבלה רגילים. אין נתוני גישה/עוגיות/מפתחות בקובצי הראיות.

לא נעשו שינויים במסד, בשרת משותף, ב־Auth/RLS, בדגלים משותפים, ב־Legacy,
