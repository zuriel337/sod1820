## ההשלמה החדשה — דפדפן מול התוצר המתארח

Chromium 154.0.8037.57 במצב headless, רוחבים 390 ו־1440 וגובה 900,
נתונים ציבוריים אמיתיים ו־`/sw.js` האמיתי. אלה בדיקות התנהגות ולא מדידות מהירות.
זהות המקור והאש ה־worker אומתו בכל הקשר. התוספת אינה מחליפה את בדיקות
הדפדפן עם הממשק הגרפי מהסבב הקודם.

| בדיקה | תוצאה |
|---|---|
| טופס פתיחת חלקים לפני לחיצה | אין שדות כתובת ואין בקשת זמינות מוקדמת |
| לחיצה על „עדכנו אותי כשנפתח” | OPTIONS אמיתי יחיד החזיר 200 ו־opening-parts-v1 דרך ה־SW; נפתח הטופס |
| מצב הסכמה | כתובת ריקה, הסכמה לא מסומנת, כפתור שליחה מושבת |
| כניסת מנהל | כניסה לחשבון קיים בסיסמה; אין אפשרות OAuth/OTP/הרשמה; קישור החזרה שומר פרמטרים חוזרים ומקטע |
| הסרה ללא טוקן | „קישור לא תקין”, no-referrer/noindex/no-store, אין קריאה לפונקציית ההסרה |
| אורח ב־code, heichal, journey, raziel, community/chat | חמשת המסלולים סגורים בשני הרוחבים; אין תצוגת מנהל שהוענקה לאורח |
| יציבות ותקלות בתרחישים החדשים | אין חריגות pageerror, אין בקשה שנדחתה בידי רתמת הבטיחות, אין רוחב דף החורג מהחלון |

כל 16 מצבי המסמך (8 בכל רוחב) עברו. נבדקו תמונות מסך של הטופס במובייל ושל
הכניסה בדסקטופ. לא נטענו פרטי חשבון אמיתי, לא נשלח טופס ולא בוצעה הסרה.
הקבלה אינה מוכיחה הרשמה, התחברות או הסרה חיובית אמיתיות.

הרצת ההשלמה משתמשת ברתמת בטיחות נפרדת ששומרת את אותה רשימת RPC לקריאה
מהבדיקה הקודמת. השירות היחיד שנוסף לקריאות המותרות הוא OPTIONS לכתובת
newsletter-signup המדויקת, ללא query או גוף. כל POST של הרשמה/כניסה, כל
GET של הסרה חתומה וכל פעולה אחרת שאינה קריאה נשארים חסומים. זה אינו שינוי
בהרשאות המוצר או ברתמת הקבלה הקודמת. סרגל Vercel החיצוני וטלמטריה חיצונית

הריצה הראשונה נעצרה לפני פתיחת דף מוצר: בקשת המניפסט קיבלה HTML במקום JSON.

הגישה השמור וגם במניפסט. באמצעות חיבור Vercel המורשה התקבל קישור גישה זמני
חדש לאותו deployment, ואז שתי בדיקות הדפדפן עברו. לא שונו SSO, דומיין,
הרשאות הפרויקט או המקור. אין לייחס את הכשל הזה לאתחול האתר או לתקיעה
ההיסטורית שסיבתה עדיין לא הוכחה.

[הריצה שנכשלה](evidence/run1/receipt.json) ו[האבחון](evidence/run1/access-diagnostic.json)
נשמרו. קישורי הגישה, cookies ופרטי auth נשארו מחוץ ל־Git. כשל הגישה אינו
מוסתר באמצעות ספירת שתי ההרצות שעברו בלבד.
