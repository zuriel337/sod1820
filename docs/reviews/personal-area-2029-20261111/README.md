## מה השתנה
- `PersonalHome2029.jsx` + `personalArea2029.css` — מסך אחד בשפת "עכשיו/עוד" (`royal2029.css`): אולם חשבון למעלה (תמונה, שם, מחובר/אורח, מטבעות: עוקב/חדשות/שלב/קרדיטים, פעולה ראשית זהובה, כניסה/התנתקות/הגדרת סיסמה), ואחריו קבוצות עם כותרות וכרטיסים קומפקטיים; רשימות ארוכות (מחקר, מעקב, רזיאל) נפתחות לפי דרישה. ספיר = צבע האזור, זהב = הפעולה הראשית והמספרים.
- `src/lib/userCenter/personalArea2029.js` — מודל טהור: כל כרטיס מצביע על בעלים קיים אחד (מודול `WriterPersonal2029Page`, route קיים, או רשימה בתוך הפאנל מאותו מקור נתונים). כרטיס סגור מציג סיבה אמיתית, לא כפתור מת.
- `SystemFrame2029.jsx` (אזור `WorkspaceProjection*`, כ־1065–1470) — בונה כרטיסים ו־slots; הכפילות של בלוקי חשבון הוסרה.
- `keyboardClearance2029` — מרווח דינמי למקלדת בנייד (visualViewport) ו־`scroll-padding`, כך שכפתור "שמירת הסיסמה" ושדות אישור אינם מכוסים בסרגל התחתון/במקלדת (גם במסך השחזור וגם מהחשבון).
