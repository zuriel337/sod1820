# איחוד האזור האישי וקומפוזיציית RTL — 2026-10-26

## תוצאה

האזור האישי של 2029 משתמש כעת בשתי מעטפות משותפות וממורכזות: חלונית `My Workspace` של `SystemFrame2029`, ומעטפת אחת לכל נתיבי `/2029/me/:module`. כיוון RTL נשמר לכיוון הקריאה וליישור התוכן בתוך הכרטיסים, אך אינו מצמיד עוד את המסך כולו לימין.

הכותרות, הניווט וקבוצות הפעולות ממורכזים; גוף התוכן העברי נשאר מיושר לתחילת השורה. רוחב המעטפת מוגבל ל־980px בנתיבי האזור האישי ול־960px בחלונית, עם שוליים מאוזנים. ההודעות משתמשות באותה מעטפת; יישור לפי שולח נשאר באחריות השרשור הקיים.

## מערכת אחת

- „האזור האישי” בחלונית המערכת נשאר הכניסה הקנונית.
- „המחקר שלי” ו„השיחות שלי” גלויים באותה חלונית.
- „השיחות שלי” פותח את מרכז השיחות השמורות הקיים גם כשהמשך השיחה עם רזיאל נעול. פתיחת רזיאל עצמו ממשיכה לכבד את הנעילה הקיימת.
- דפי „הדף שלי”, „פרופיל ותמונה”, „הודעות”, „מעקב ועדכונים” ו„ההתקדמות שלי” צורכים את אותה מעטפת, אותו רוחב, אותו ניווט וחזרה מדויקת.
- לא נוספו Provider, store, session, transport, API או מקור נתונים.

## Preview של הפרופיל

ה־Frontend Preview המלא משתמש בנתיב הקיים `/api/contributor-self` במקום ב־fallback של HTML. `GET` ממשיך לבצע Auth ובעלות כרגיל. אורח מקבל `login_required`, והמסך מציג בקשת התחברות ברורה.

ב־Vercel Preview בלבד, `POST` לנתיב נחסם בשרת עם `403 preview_read_only` לפני Auth ולפני כל RPC. אין נתוני פרופיל מדומים ואין עקיפת הרשאות. Production אינו מקבל את החסם הזה.

## מובייל ונגישות

- ניווט המודולים נעטף לשתי עמודות ב־320px וב־390px ולעמודה אחת מתחת ל־330px.
- יעדי הפעולה במעטפות הם 44×44px לפחות.
- אין גלישה אופקית במטריצת הבדיקה.
- גלילה במקלדת ובמגע אומתה ברוחבים 320px ו־390px.
- חלונית Workspace משתמשת בגובה `dvh` במובייל כדי לשמור את כל התוכן נגיש לגלילה.

## אימות

בדיקת הדפדפן רצה על build של 2029 עם ה־Auth, ה־ResearchProvider, ה־System Frame, עורך הדף ותיבת ההודעות הקיימים. רק תשובות HTTP הוחלפו ב־fixtures סינתטיים; לא בוצעו כתיבות חיות.

- 72 מצבי מודול: 6 מודולים × 4 רוחבים (320, 390, 768, 1440) × 3 ערכות (יום, קלף, לילה).
- שוליים שווים: 12/12px ב־320, 390 ו־768; 100/100px סביב מעטפת 980px ב־1440.
- 12 מצבי Workspace נוספים. „המחקר שלי” ו„השיחות שלי” נגישים, ומרכז השיחות נפתח.
- 0 קריאות ל־`ai-analyze` או ל־`research-run` בפתיחה ובניווט.
- Exact Return, החלפת חשבון ללא זליגה, עורך, תמונה ציבורית, הודעות, מעקב ומצבי אורח/לא משויך/מעורפל/כשל נשמרו.
- קובצי הראיות נמצאים ב־`docs/reviews/personal-area-balanced-rtl-evidence-20261026/`.
