# איחוד ההמחשות של שיטות הגימטריה — מפה, תוכנית ותצוגות לאישור (27.11.2026)

> **ענף `claude/gematria-structure-unify-20261127`, לא מוזג, לא נפרס, בלי PR.** לא שונתה אף נוסחה ולא הוקם מנוע: כל מספר שמוצג הוא מספר של עקבות המנוע הקנוני (`gematria_method_trace`), דרך `projectGematriaTrace` הקיים שנכשל סגור על עקבה שלא אומתה. ההוכחה: ריבוע 5787 נכון (`fn_ribua`, parity מאומת), והעקבה כבר מכילה כל מה שנדרש לתצוגה המלאה.

## הממצא
1. **מפזר אחד קיים וכמעט לא בשימוש:** `SpatialMethodStage2029` מכיר שלבים ייעודיים (מילוי ובני משפחתו, רגיל, מסתתר, קדמי, משולש מילה); כל שאר השיטות נופלות בו ל־`TraceFamilyStage2029`, שמצייר **רשימת כרטיסי צעדים כללית** לכל סוג עקבה.
2. **`UnitGematria2029` עוקף את המפזר:** לכל גילוי שאינו מורכב הוא שולח ישר ל־`TraceFamilyStage2029`. לכן בבית ובפוסטים גם רגיל או מילוי מוצגים ככרטיסים כלליים, ובדף המספר אותה שיטה מוצגת בשלב ייעודי. אין קו אחד.
3. **ריבוע:** בעקבה, `CUMULATIVE_PREFIX` עם `per_word_reset`: לכל מילה קידומות וערכי קידומות (`prefix_subtotal`) וסכום מילה (`word_subtotal`); לתפרצי בתשפז: 400·480·680·770·780 = 3,110, ו־2·402·702·782·789 = 2,677, ויחד 5,787. הכרטיס הכללי הציג צעד אחד בכל פעם, בלי משולש, בלי סכומי המילים ובלי המשוואה.
