## 1. North Star — one governed adaptive research world model

SOD1820 is no longer planned merely as a website with advanced pages. The target is a governed, adaptive research world model that can serve humans, AI agents, search systems and future spatial interfaces from one semantic reality.

```text
ONE TREE — unity law
    ↓
ONE REALITY GRAPH — stable identities + typed relations
    ↓
TEMPORAL WORLD MODEL — what happened / what was known / what was believed when
    ↓
RESEARCH OS
    ├─ Identity
    ├─ Evidence / Sources / Provenance
    ├─ Findings / Calculations / Interpretations
    ├─ Dataset / Derivation / Research Structure
    ├─ Truth / Governance / Access
    └─ Capability Fabric
         ├─ Gematria
         ├─ ELS
         ├─ governed numeric operators
         ├─ Books / Sources / Tanakh
         ├─ Graph / Events / Reality
         ├─ Person / Family context
         └─ future engines and capabilities
    ↓
RESEARCH COMPOSER / CONTEXT COMPILER
    ├─ resolve identity first
    ├─ authorize before evidence
    ├─ retrieve bounded relevant reality
    ├─ execute canonical capabilities
    ├─ compose Universal Findings
    ├─ rank/explain by context
    └─ produce bounded replayable Context Pack
    ↓
ADAPTIVE PROJECTIONS
    ├─ HUMAN: Home · World · Heichal · Posts · Archive · Workspace · Journeys
    ├─ RAZIEL: conversational research intelligence over the same context
    └─ MACHINE: Search · structured data · feeds · answer/retrieval agents
    ↓
2D · 3D · AR · VR · multilingual · API · future renderers
```

No layer above is permitted to create a second truth graph merely for convenience.

### Core distinction

- **One Tree** = unity law.
- **One Reality Graph** = implementation of identities and relations.
- **Research OS** = evidence, sources, calculations, findings, interpretation and governance.
- **Context Compiler** = selects and composes only the relevant authorized slice.
- **World / pages / Journeys / lenses** = contextual projections.
- **Raziel** = intelligence/interface over the same governed reality.

## 2. Minimal semantic boundary — Identity / Evidence / Composition / Projection

This boundary governs future ontology decisions before adding new types/tables.

### A. Identity — “what thing is this?”

Stable semantic identities may include, when qualified:

- Number
- Book / Source Work
- Event
- Person / Organization / Place
- persistent Canonical Subject / Topic
- Publication / Post
- reusable research artifact/structure only when it survives representation changes and merits durable identity

Identity does **not** automatically imply a public page.

### B. Evidence — “what supports or records it?”

Examples:

- source / witness / edition / digital object / exact locator
- calculation / method trace
- extraction
- observation
- Finding / Claim / Question
- provenance and attribution roles

Exact wording is preserved where letters/orthography affect research meaning.

### C. Composition — “how is research assembled?”

Examples:

- Dataset Definition
- Dataset Instance / Run
- Derivation / Procedure
- Research Structure
- Research Object
- multi-source composition

Required lineage where applicable:

`Source/Witness/Locator → Dataset → Derivation → Research Structure → Representation`

Do **not** add `topic`, `dataset`, `research_structure` or `witness` as new DB types merely because the concepts exist. First prove a stable identity/lifecycle owner cannot be represented safely by existing primitives.

### D. Projection — “how do we see/use the same reality here?”

Examples:

- World
- Dynamic Lens
- page / hub / dossier
- timeline / graph / list / visual view
- temporary AI Journey
- 2D / 3D / VR / AR
- Hebrew / English / future language
- Home / Archive / Number / Book contextual views

Projection changes emphasis and ordering; it does not fork truth.

## 3. Time, interpretation and truth are first-class

SOD1820 must model a changing reality and changing human understanding without rewriting history.

Where applicable keep separate:

- `occurred_at` — when the real-world event happened;
- `source_published_at` — when the source/publication appeared;
- `discovered_at` — when the finding was noticed;
- `researched_at` — when SOD1820 analyzed it;
- `stream_at` — when a Reality item entered/resurfaced in the current stream.

### Interpretation history

- historical interpretations are preserved with source/time/context;
- a current/default interpretation may change;
- public surfaces foreground the current understanding but allow deeper timeline/history;
- factual/engine evidence remains distinct from interpretation;
- versioning is lightweight: only material research/source/rule/conclusion changes create meaningful research history.

### Independent axes

Never collapse these into one badge/state:

- epistemic type
- verification
- governance/canonicality
- publication/access
- indexability
- featured/editorial prominence
- operational availability

**Public ≠ Indexable ≠ Featured.**

## 4. Product homes — stable destinations, adaptive ways to reach them

The future global navigation is built from a small number of stable semantic homes, not from every current tool/component.

### Stable global homes

1. **Home / Discover** — gateway/orientation/discovery.
2. **World** — shared knowledge reality and contextual exploration.
3. **Heichal** — deep research/product environment inside the same World.
4. **Updates / Posts** — first-class editorial/publication surface.
5. **Archive** — visual/media/history umbrella.
6. **My Workspace** — one personal projection of owned/saved/ongoing state.

### Global capabilities, not top-level destinations

- Universal Search / Command
- Raziel
- Personal Attention / notifications
- account / workspace entry
- language
- Share / Save / Follow / Add-to-Research

A new tool does not earn a global navigation item merely because it exists. It first resolves its semantic home.

### World

World is the shared semantic workspace. Tree/graph/list/timeline/source/visual/spatial are **renderers/lenses inside World**, not parallel product universes.

### Tree

Do not lock `עץ המספרים` or `עץ ההתכנסויות` as future architectures. A modern **עץ** may be a visually important World projection, including a number-focused view, while remaining one lens over One Reality.

### Heichal

Heichal answers: **what do I want to do to the selected research context?**

First-class research product/capability families preserved in the architecture include:

- Number Page / numeric research
- Gematria
- ELS / letter skips
- Person / Life Journey
- Books / Sources and source inspection
- method/trace/compare/reverse/numeric operators as composed tools
- future spatial and other engines through the same Capability Fabric

Heichal owns no second graph or truth store.

### Beit Midrash

Beit Midrash remains learning/explanation/study/community where appropriate: methods, teaching, lessons and guided learning. It is not the semantic owner of all Topics/Convergences and is not another computational engine.

## 5. Topic becomes Dynamic Lens first, Canonical Subject only when justified

Legacy `topic_cards`, Convergence pages, categories and tags do not define the future ontology.

### Default behavior

A clicked/searched concept may open immediately as a **Dynamic Lens** composed from approved One Reality knowledge without creating a permanent identity/page.

### Promotion behavior

If the subject becomes important, persistent, rich or repeatedly used:

`Dynamic Lens → system proposal → Human Gate → Canonical Subject/Topic identity → optional public page`

Important rules:

- Topic is not a folder.
- Topic is not the navigation hierarchy.
- Category ≠ Topic.
- Tag/search term ≠ Topic.
- Post ≠ Event.
- hierarchy is dynamically projected from graph/context.
- aliases/languages/time-slices resolve toward one stable subject identity when promoted.

Search/click should foreground the **reality itself** — subject, events, people, relations, timeline, findings — then publications, rather than degrading into a generic post search page.

## 6. AI-native experience — adapt the interface to the new research fabric

The new AI integration changes experience design, but it does not erase stable product homes or semantic structure.

### Home / Discover

Home is a calm gateway, not a widget warehouse and not a fixed dashboard that must expose every capability.

It must have one stable public baseline for anonymous users, search engines and sharing. Above that baseline, an authorized returning user may receive contextual projections such as:

- continue where you stopped;
- what changed since your last visit;
- current/relevant Reality items;
- recommended/unfinished Journey;
- direct Search/Command entry;
- Ask Raziel from the current context.

**Personalization changes ranking/emphasis, not canonical truth.**

The exact Home module order remains OPEN until the AI-Native Experience Reconciliation pass and Global Now ranking gate are complete.

### Universal Search / Command

Search is an intent entry point, not only a keyword box.

It may resolve:

- stable identities;
- Dynamic Lenses;
- semantic actions;
- current/personal research context;
- exact routes/locators;
- authorized tool execution paths.

Examples: open 1820, compare two numbers, inspect a source, resume my Journey, ask Raziel, open ELS in the current context.

### Adaptive World

A World around a Number, Book, Event, Subject or Person is assembled contextually from the same graph/evidence. It need not use one rigid template.

Context may change emphasis:

- source-heavy when entered from a Book;
- numeric-heavy from a Number;
- temporal from an Event/Reality path;
- path-oriented inside a Journey;
- personal only when authorization allows.

### Raziel

Raziel is the conversational **Research Intelligence Layer / Companion**.

He may:

- understand current context;
- invoke authorized canonical tools/engines;
- compare evidence;
- explain why a relation appears;
- navigate to exact sources/findings;
- propose candidate relations;
- build temporary personal Journeys from approved knowledge;
- help operate the site without becoming a second site/graph/truth system.

Response depth and compute budget are adaptive. Simple questions should not pay deep-research cost; hard questions may escalate.

## 7. Capability Fabric + Context Compiler — the lower AI/research infrastructure

This layer is infrastructure for the whole upper system, not a Raziel-only implementation.

### Capability classes

- **Engines:** Gematria, ELS, future deterministic/search engines.
- **Operators:** Zero Navigation/Scale, Shitat HaEchad Alef, Moment/Clock and future governed numeric transforms.
- **Evidence sources:** Books, witnesses, Tanakh, Posts, PDFs, media/source loci.
- **Reality/context:** Graph, Events, Reality signals, persistent subjects.
- **Personal context:** Person/Family identity + authorization + private research state.
- **Traversal:** Journeys/Research Paths.

Each future capability joins through its canonical owner + adapter/output contract. Do not hard-code the future system to the current engine list.

### Identity-first order

```text
Question / action
→ resolve semantic identity
→ resolve authorization/privacy
→ understand current Research Context
→ select capabilities
→ execute at source-native owners
→ adapt results to Universal Finding(s)
→ account for dependence / dedup
→ explainable contextual ranking
→ explicit coverage / failures / gaps
→ resolved run snapshot BY VALUE
→ bounded Context Pack
→ Raziel / World / Journey / other consumer
```

The composer does not calculate Gematria or ELS itself. It orchestrates canonical owners.

### Context cost law

> **More knowledge in SOD1820 must not mean more tokens per conversation. As the corpus grows, context selection must get smarter.**

Only the relevant authorized graph/evidence slice is compiled for AI. Stable engine facts/results should be reusable/cached where safe rather than re-reasoned every turn.

### Privacy gate

Private Person/Family evidence is bounded **before** it reaches a bundle/context/model. Context never widens authorization.

### Gematria Root Gate

Operational rule remains:

> **SCAN EVERYTHING; ROOT ONLY WHAT BECOMES GEMATRIA RESEARCH.**

Scanning/tokenizing/background calculation does not auto-admit every expression into the global Gematria corpus. An expression used as durable Gematria research must resolve through the canonical corpus/root gate first.

## 8. Person / Life / Family — private research over the same One Reality

Person/Life is a first-class product context, not a separate personal engine or graph.

Potential inputs include:

- names;
- family/relationships;
- dates and life events;
- repeating numbers;
- recurring/ordered clock moments;
- screenshots/photos/signals supplied by the user;
- a Number/Event/Book/Visual/ELS item encountered anywhere in SOD1820.

A personal research chain may compose:

`Person/Family → Time/Moment → governed numeric operator → Number/Gematria → ELS → Sources → Graph → Finding → Raziel`

while preserving original input, timestamp/timezone/context, method/operator/version and provenance.

### Truth boundary

`Personal hint ≠ Fact ≠ Canonical Relation ≠ Divine Sign.`

Personal relevance is recommendation/interpretation, not proof.

### Private overlay

Private notes, personal connections, Journeys and AI relevance attach to the same canonical identities without contaminating the public graph.

A user may explicitly submit private material to public research intake. Submission creates a candidate/review path; it never promotes automatically.

### Personal Reality

A contextual projection may answer “what in reality touches my current research/world?” using authorized personal/research/follow signals. It is not a new feed/store.

## 9. Reality / Global Now / Archive / Visuals

### Reality Stream

Reality Stream is a first-class **temporal World projection** answering roughly:

> What is happening now, resurfacing now, or awakening around entities/numbers/subjects?

It is not Gallery and not a second knowledge tree.

Future semantic shape:

`Reality Signal / Event → Representation(s) → canonical entities/numbers/subjects/persons/posts/sources/time → World/Research Context`

Keep separate:

- **HOT** = current human demand/search interest;
- **REALITY** = stream/reality relevance or awakening/trend;
- **CORE** = structural/corpus strength.

None is a truth score.

### Global Now

Global Now evolves from posts-only toward a typed update projection. Candidate types include:

- Post/publication
- Reality Signal
- Subject/Topic update
- Book/Source addition
- ELS/Cipher publication
- Research publication/finding
- Journey/product release
- other governed change events

It must deduplicate multiple representations of the same underlying event/identity.

**OPEN GATE:** exact prominence/ranking/recency/curation/dedup policy must be owner-resolved before final Home composition. Do not bury ranking semantics inside navigation or a Home component.

### Archive — accepted future direction

The visual-history umbrella should normalize toward three primary public projections:

1. **זרם המציאות** — NOW
2. **אוצרות** — BEST / CURATED
3. **גלריות** — ALL / ARCHIVE

Conceptual hierarchy: **Now → Best → All**.

Legacy public Pool/Sets is not a required primary destination; useful capabilities may be re-homed after consumer/deep-link verification.

### Home Reality preview

Home should show only a compact gateway/preview, not another full copy of Reality controls/filters/river.

### Gematria Visual

Gematria Visual is a structured representation generated from canonical engine/research data, not a screenshot and not a second truth object. One representation may appear in Post, Gallery, Treasures, Reality, Number/World, Home, Journey and external share.

### Media Viewer

One shared Viewer owner. Default opens the **whole image without crop**; reading/zoom modes are explicit secondary states.

## 10. Books / Sources / Research Structures

A Book is a first-class source identity. Library, reading, source map, research view and 3D/spatial view are projections.

Preserve the source chain:

`Work/Book → Edition → Textual Version → Witness → Digital Object → Locator/Page/Block`

Research may derive:

`Extraction → Dataset → Calculation/Procedure → Finding → Research Structure → Representation`

### Contextual Source Gap

When active research lacks sufficient source evidence:

1. search existing owned Books/Witnesses/locators first;
2. if insufficient, recommend the missing source/book and explain the target claim/reason/priority/availability;
3. recommendation remains a research task, not evidence;
4. resolve/supersede the gap when exact source evidence is acquired.

### Spatial / 3D

Spatial is a renderer/capability tier over the same research structure. Geometry escalates only when it carries research meaning. 3D must not be used merely to look advanced.

## 11. Journey — traversal, not copied content

Journey is a path through existing identities/evidence/context.

- WORLD JOURNEY and LIFE/PERSONAL JOURNEY are entry modes over the same research substrate.

- exact return/reopen must preserve subject, selection, source locus, method/tool state and Journey position.

**Live reality:** Journey foundation/seed concepts exist, but current `research_paths` population is **0**. Do not present the modern Journey product as already materialized.

## 13. Governance / Human Gate 2029+

### Promotion

AI/engines may create evidence, candidates, recommendations and explanations from approved facts. They may not silently create canonical semantic identity or novel public meaning.

### Delegation

Trusted researchers/editors may receive bounded approval authority by domain/level.

Within delegated scope, ordinary approvals may publish. High-risk changes escalate according to fixed always-escalate categories plus risk scoring.

Always-escalate examples include:

- changing top-level interpretation;
- canonical identity creation/merge changes;
- destructive deletion;
- major/extraordinary claim;
- sensitive cross-domain change.

### Merge / retirement

Canonical identities are normally:

- merged into one survivor with aliases/redirects;
- retired;
- superseded;
- preserved historically.

Hard deletion is exceptional.

Repeated knowledge across multiple historical Posts does not justify deleting the Posts. Deduplicate the **Finding**, preserve the publications.

## 17. Golden acceptance philosophy

Do not certify the architecture using one favorite number or one page.

A successful system must handle all of these without special-case architecture:

1. public Number research;
2. exact Book/source evidence;
3. real-world Event + separate publication/discovery times;
4. Dynamic Lens promoted later to persistent subject;
5. reconstructable Dataset/Structure with mixed verification state;
6. private Person/Family research with strict authorization;
7. ELS and Gematria as distinct engines in one composed query;
8. temporary AI Journey and official published Journey;
