# scene.v1 → Blender bridge (M2)

Blender, `.blend` and GLB are **derived projections** of the compiled `scene.v1` (owner: `experience_governance_foundation_v1_law` v8 + `SOD1820_DESIGN_CONTRACT_V1.md` + `spatial_research_runtime_vision_v1`). No new system, owner or store.

- `src/lib/spatial/sceneExport.js` — renderer-neutral export (`sod1820.scene.v1.export/1`): the full scene, a derived `display` payload (via `resolveSceneTraceValue`, never inside identity), an optional projection-only camera rig, and `parity_reference` (JS resolver output).
- `scripts/spatial/export-scene-v1.mjs` — CLI: `--trace <trace.json> [--camera] [--out f]`, `--compare <export.json> <blender-parity.json>`.
- `scripts/spatial/scene_v1_to_blender.py` — importer + parity exporter + still render + optional derived GLB. Runs under `blender -b -P … -- --scene … --parity …` or with the `bpy` module (`SOD_BPY_PYTHON=<python with bpy> npm run test:spatial-scene-v1`).
- Coordinates are used raw (y-up). Rotation is `R = Rx*Ry*Rz` (Blender's `XYZ` Euler is `Rz*Ry*Rx`, so local matrices are built explicitly), `local = T*R*S`, `world = parent*local`. Parity tolerance is explicit (float32 in Blender): see `BLENDER_PARITY_TOLERANCE`.

## M3 — Hebrew glyph/vector asset lineage (no new owner; EXTEND_EXISTING under the same owners)
One versioned lineage, reused by Web/SVG, R3F, Blender, future ELS/Torah projection and video:
`source glyph (font outline, read-only, never committed/embedded) → normalized path-only SVG → sha256 → manifest → scene.v1 asset_ref`.
- `src/lib/spatial/hebrewGlyph/v1/` — `manifest.v1.json` (+ identical `manifest.v1.js`) and 27 `heglyph-XXXX.svg` (22 letters + 5 finals). Semantic identity is the Unicode codepoint (+ existing LetterAnatomySpec); `glyph_id = heglyph:<HEX4>`. Finals carry their own id plus `base_codepoint`/`base_glyph_id`. `truth_tier = REPRESENTATION`; no numeric/gematria/ELS field is allowed (validator-enforced).
- `scripts/spatial/build_hebrew_glyph_assets.py --font <ttf> [--check]` — deterministic generator (needs `fontTools`; runtime never does). Profile `v1`: em 1000, baseline y=800, view height 1000, y-down, 2 decimals, commands `M L Q Z`. `--check` proves committed bytes == regenerated bytes.
- `scripts/spatial/validate-hebrew-glyph-assets.mjs` — validation CLI (27 identities, no duplicate codepoint, final linkage, path-only SVG, checksums, JSON==JS).
- `src/lib/spatial/hebrewGlyphAssets.js` — manifest lookup, `buildGlyphAssetRef` (identity + version + content_hash only; **no tessellation bytes**, so it is safe inside the scene signature), fail-soft `resolveGlyphAssetRef`, and the shared placement formula (`glyphPlacement`/`glyphPointToLocal`), mirrored 1:1 in `hebrew_glyph_lineage.py`.
- scene.v1 (Mistater) letter nodes gain additive `asset_ref`; the projection signature now binds it (fixtures regenerated). Nodes without an asset simply omit it.
- Web: `MistaterScene3D2029.jsx` extrudes the manifest SVG (lazy `?raw` import + `SVGLoader`); on missing/stale asset or load failure it keeps the canvas-text/box fallback. Blender: `build_glyph_curve()` rebuilds the same path as an extruded 2D curve (no Blender font object); the parity export adds `assets` (node → glyph_id/content_hash) for Web↔Blender asset parity.
- **Source gate: `SOURCE_GAP`.** No Human-Gate-approved Hebrew visual profile exists. The candidate is Heebo ExtraBold (`api/_assets/heebo-800.ttf`, SIL OFL 1.1 verified in the font's name table, sha256 in manifest). Every glyph is `CANDIDATE_NOT_VISUAL_CANONICAL`; promotion (or a different profile) is a ZURIEL decision. Re-running the generator with another font/profile yields a new `vector_version`/`profile_id`, never a silent change.
- **Future atlas/LOD rules (hooks only):** `atlas.group/slot/batch_key` order glyphs for a single MSDF/SDF atlas; `derived.{msdf,sdf,glb_lod}` hold refs to artifacts *derived from the SVG lineage* (never a second source). ELS/Torah corpus letters are rendered by instancing `glyph_id` through the existing occurrence adapters — M3 does not create corpus meshes or a second Torah-letter store.
