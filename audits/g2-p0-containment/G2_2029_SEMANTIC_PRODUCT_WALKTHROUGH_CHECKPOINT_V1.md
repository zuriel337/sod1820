## Product-family walkthrough decisions

### Discovery / Search / Explorer
Foundation can return identities, Findings, Dynamic Result Sets and suggested next research actions without minting Topic/World identity. 358 may return a rich result; 359 may be sparse. PASS. Ranking/presentation is later.

### Entity Hub — Number / Expression / Concept / Book / Event / Person
A Hub projects one qualified identity and related calculations, Findings, Sources, Media, ELS, Events, Posts, Books and actions. Number 358 is distinct from exact Expression `משיח` and from a Concept/Anchor carrying semantic meaning. PASS semantically.

### Research World / Dynamic Lens
A World is a context/lens over the same Reality, appearing only when real depth exists. 358 qualifies as a strong Golden World; 359 need not. Shared-artifact identity is a redesign-risk dependency (see G2-R2).

### Journey / Research Path
Journey is traversal state over one Reality, not a second ontology. Existing `research_paths/research_path_revisions` now support versioned paths and first-class negative/missing outcomes. Runtime wiring is later implementation. PASS Foundation.

### Raziel
Raziel consumes the same Research OS/Context/Result Bundles and selects capabilities dynamically. No Raziel Graph or parallel truth system. Personal runtime remains privacy-gated. PASS directionally; P0-C privacy challenge still open.

### My Research / Workspace
Personal surface is a projection over saved/context/path/notifications/contributions/access owners, not a second store. Saving 358 stores user relation/context to 358, not a duplicate 358. PASS.

### Gematria / Numeric / Patterns / Sequences
Capabilities produce governed findings/results with method/version/selection/dependency provenance. Dependent transforms cannot inflate independent evidence. PASS semantic Foundation; G3 runtime/Golden implementation later.

### ELS / Cipher Research
ELS is a governed capability/Research evidence layer, not a separate ontology. Result coordinates, corpus, direction, replay and negative results survive. However active `els_research_layer_law v2` still states every ELS result becomes graph Edges; this conflicts with Reality Graph v5/Human-Gate identity/promotion semantics. G2 RETURN.

### Books / Sources / Reader
Semantic separation Work != Book != Edition != Textual Version != Witness != Digital Object != Locator/Snapshot is already owned. Historical/current render honesty is required. Storage path is currently Extension Point, not permission for a new Source Registry. PASS semantic owner; implementation may extend `research_objects.meta.ext`/qualified graph identities later.

### Posts / Publications
A Post is Publication/Representation related to Anchors/Findings/Sources/Events. Publication is not truth. Live 358 stress test exposes a real migration gap: 148 content mentions but 0 modern `post_gematria_links`; only 8 legacy grapher edges. G2 RETURN: modern provenance-bearing Post↔Research Reality relation migration is required; never bulk-promote by text match alone.

Foundation-maximal calibration: where the live Foundation supports it, Post should be treated as an authored/historical Research Narrative over One Reality rather than a self-contained knowledge silo. Preserve the authored publication state and authorship; project current research around it without retroactive rewrite; support typed semantic references to shared identities, temporal “then vs now”, Explain-Why lineage, shared-media identity, and continuation into World/Heichal/Journey/Raziel. Exact layout remains G3/Experience-owned.

### Gallery / Media / Reality Stream
Media is a representation/artifact with provenance and typed subject relations; placements/context are not intrinsic truth. Same artifact may appear in Post/Gallery/Timeline/World without becoming multiple evidence sources. Shared-artifact identity is required. `one_dynamic_gallery v1` also carries stale identity language (“one living gallery entity”) conflicting with Reality Graph v5 projection semantics. G2 RETURN for semantic reconciliation, while the experiential intent of one dynamic gallery may be preserved for later Projection.

### Person / Personal / Cohort
Same canonical identities/capabilities, different authorized contextual-strength profile. 1426 may be strong personal/cohort and weak globally. Within-person recurrence != cross-person independence. PASS contract; runtime requires P0-C/participate-analyze enforcement and later privacy challenge.

### Community / Contributions
Contribution becomes candidate research state and follows engine verification + Human Gate. Popularity/participation never auto-promotes truth. PASS.

### Access / Premium / Credits
Access policy is independent of Truth and presentation. Same 358 Reality under every entitlement; only available depth/actions differ. Exact products/prices/tiers are later Human-Gate/G5 product decisions. PASS.
